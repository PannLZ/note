| 2      | **可信金融 RAG / 长上下文 / 幻觉检测**          | 金融落地最刚需，容易做出可验证贡献                           |
| 3      | **时间安全的 LLM Agent 投资决策**               | Agent 很热，但金融里最大问题是泄漏、回测幻觉和可审计性       |
| 4      | **LLM + 时序/事件/因果的市场预测**              | 比“纯股票预测”更有顶会味道，适合 ACL/KDD/NeurIPS             |
| 5      | **金融 LLM 强化学习 / 偏好优化 / 过程奖励模型** | 2025-2026 开始冒头，适合做 reasoning、risk-aware decision    |
| 6      | **金融知识图谱 + LLM / 图学习**                 | KDD、AAAI/IJCAI 里金融图学习密度高，可和 RAG/Agent 结合      |
| 7      | **监管、合规、风险控制中的可信 AI**             | 行业价值很高，论文空间比“交易收益率”更稳                     |
| 8      | **金融专用评测与数据治理**                      | 好发但容易卷，必须做动态、抗污染、真实流程，而不是普通 benchmark |



| 很适合           | **可信金融 RAG / 幻觉检测 / 长文档 QA**       | 完全可做。embedding、reranker、RAG、引用校验、本地 7B/14B LLM 都够。 |
| ---------------- | --------------------------------------------- | ------------------------------------------------------------ |
| 很适合           | **金融 benchmark / 数据治理 / 防污染评测**    | 完全可做。主要瓶颈是数据设计，不是算力。                     |
| 很适合           | **金融事件抽取 + 市场事件分析**               | 7B/14B LoRA 微调、事件抽取、公告/新闻分类都可做。            |
| 适合             | **LLM + 时序/事件/因果预测**                  | 可做。时序模型、事件编码器、LLM 生成因子都能跑，关键是回测设计。 |
| 适合             | **金融知识图谱 + LLM / 图学习**               | 中小规模图没问题。超大企业图、链上交易图可能受内存/采样效率限制。 |
| 适合但要控规模   | **多模态金融文档/图表推理**                   | 可做现成 MLLM + RAG + OCR + 表格解析 + verifier。可微调 7B/8B/14B 多模态模型，但不建议全参训练。 |
| 适合但实验成本高 | **时间安全投资 Agent / 多智能体投研**         | 可做。算力不是最大问题，主要是多轮推理、回测、API 调用和实验次数。 |
| 勉强可做小规模   | **金融 LLM 强化学习 / DPO / GRPO / PRM**      | 7B 级小规模 DPO/ORPO/GRPO 可以做；14B 要很节制；大规模 RLHF 不现实。 |
| 不建议           | **金融大模型继续预训练 / 多模态基础模型训练** | 单卡 L20 不适合。成本、数据、训练稳定性都不划算。            |
