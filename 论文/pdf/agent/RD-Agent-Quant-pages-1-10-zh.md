### 摘要

金融市场由于其高维性、非平稳性和持续波动性，给资产收益预测带来了根本性挑战。尽管大语言模型和多智能体系统已经取得进展，当前的量化研究流程仍然存在自动化程度有限、可解释性较弱，以及因子挖掘和模型创新等关键组件之间协调割裂的问题。

本文提出面向量化金融的 R&D-Agent，简称 R&D-Agent(Q)。这是第一个面向数据中心化设计的多智能体框架，旨在通过协调式的因子-模型联合优化，自动化完成量化策略的全栈研发。R&D-Agent(Q) 将量化流程拆解为两个迭代阶段：Research 阶段会动态设置与目标对齐的提示词，基于领域先验形成假设，并将其映射为具体任务；Development 阶段使用代码生成智能体 Co-STEER 来实现特定任务代码，并在真实市场回测中执行。

这两个阶段通过反馈阶段连接起来。反馈阶段会全面评估实验结果，并将其用于后续迭代，同时使用多臂老虎机调度器进行自适应方向选择。实证结果表明，R&D-Agent(Q) 在使用比经典因子库少 70% 因子的情况下，年化收益最高可提升到其 2 倍，并且在真实市场中优于最先进的深度时间序列模型。其因子-模型联合优化在预测准确性和策略稳健性之间取得了较强平衡。

代码地址：https://github.com/microsoft/RD-Agent

## 1 引言

金融市场是高维、非线性的动态系统，其收益序列表现出厚尾分布、时变波动性以及复杂的横截面依赖关系。这些特征意味着资产价格同时受到宏观因素、微观结构信号和行为反馈的驱动，使得金融预测远比常规时间序列预测更加困难。

在数据爆炸式增长、计算能力提升和 AI 技术突破的推动下，资产管理行业正在从经验驱动范式转向数据驱动范式。在这一转变中，量化投资由于以下原因逐渐成为主流：

1. 通过“数据-因子-模型”循环实现高效决策；
2. 通过集成风险控制实现可重复执行；
3. 在策略趋同不断增强的情况下，更精准地追求超额收益。

图 1 展示了现代量化研究流程。微软开源项目 Qlib 简化了数据处理和回测，减轻了大量重复工程负担。因此，这一转变将量化研究的重点进一步推向其核心组件：因子挖掘和模型创新。

因子挖掘从 Fama-French 等封闭形式的风险-收益模型，发展到演化式符号回归，最近又发展到强化学习对因子组合的优化。模型创新则从经典自回归模型，发展到机器学习模型，再到序列到序列的深度学习结构，例如 GRU 和 LSTM。更新的发展还包括专门的时间序列模型，它们将信号分解为趋势和季节成分，或改进注意力机制以处理长程预测。

尽管已有这些进展，量化研究仍面临三个关键限制：

1. 自动化有限。当前工作流在假设生成、编码和调参中需要大量人工干预，导致迭代缓慢且容易带入偏差。此外，半自动系统难以达到快速变化市场所要求的响应能力和规模化能力。
2. 可解释性较差。现有基于 LLM 的智能体往往直接从语言交互中产生交易信号，而不是基于有支撑的因子构造或透明的模型逻辑，因此容易产生幻觉。这阻碍了它们在真实交易中的采用，因为实盘交易要求可解释性和风险控制。
3. 优化割裂。量化流程横跨数据处理、因子挖掘、模型训练和评估，但当前方法缺少系统性的任务分解或智能体级协调。这种孤立结构限制了跨阶段反馈和联合性能提升。

图 2：R&D-Agent(Q) 的概念图。R&D-Factor 和 R&D-Model 模块分别代表因子开发和模型开发的完整优化循环。

为了解决这些挑战，我们提出 R&D-Agent(Q)，这是第一个面向数据中心化的多智能体框架，用于通过协调式因子-模型联合优化，自动化完成全栈量化策略开发。我们的框架将量化研究拆解为两个核心阶段中的五个阶段：Research 和 Development。

在 Research 阶段，Specification Unit 会根据优化目标动态生成与目标对齐的提示词。随后，Synthesis Unit 会基于先前结果生成面向任务的知识森林，并生成新的因子或模型假设，再将这些假设映射为可执行任务。

在 Development 阶段，我们引入 Co-STEER，这是一个代码生成智能体，利用链式思维推理和基于图的知识存储。Implementation Unit 将假设翻译为代码，而 Validation Unit 会执行真实市场回测。Analysis Unit 使用统一指标进行评估，并使用多臂老虎机调度器自适应选择下一步优化方向。

这形成了一个封闭的“假设-实现-验证-反馈”循环，支持策略持续、面向目标地演化，标志着朝智能化、自主化量化研究迈出一步。

本文的主要贡献如下：

1. 端到端自动化与透明性。R&D-Agent(Q) 是量化金融中第一个面向数据中心化的多智能体框架，它以可验证输出自动化整个研发过程，从而增强可解释性并降低幻觉风险。
2. 高性能研发工具。在 Research 阶段，R&D-Agent(Q) 通过结构化知识森林模拟分析师工作流，从而生成连贯且高质量的假设。在 Development 阶段，我们提出 Co-STEER，一个面向数据中心化任务的知识演化智能体，用以提高因子和模型代码生成的准确性和效率。
3. 强实证表现。真实股票市场中的大量实验表明，在成本低于 10 美元的情况下，R&D-Agent(Q) 相比基准因子库实现了约 2 倍的 ARR，并且使用的因子数量减少了 70% 以上。它还在更小资源预算下超过了最先进的深度时间序列模型。其交替式因子-模型优化进一步在预测准确性和策略稳健性之间取得了优秀折中。

## 第 3 页

## 2 R&D-Agent(Q)

基于图 1 和附录 B 中正式化的量化研究流程结构，我们提出 R&D-Agent(Q)，一个用于迭代式因子-模型研发的数据中心化多智能体框架，强调自动化、可解释性和效率。我们将量化流程拆解为五个由 LLM 驱动的单元，每个单元主要关注信息收集和 LLM API 交互：

1. Specification：场景定义；
2. Synthesis：想法生成；
3. Implementation：代码开发；
4. Validation：回测；
5. Analysis：结果评估和任务调度。

在统一的输入-输出约束下，这些单元运行在一个闭环周期中，模拟人类量化研究员的试错过程。与人工工作流不同，R&D-Agent(Q) 能够连续自主运行，支持因子和模型组件的动态联合优化。此外，每一轮的假设、实现和结果都会被持久存储，使知识能够累积增长，并随着时间推移支持越来越充分的决策。

图 3：R&D-Agent(Q) 由五个功能模块组成，它们在连续迭代循环中协作，为真实金融市场生成高效量化因子和模型。

### 2.1 Specification Unit

Specification Unit 是 R&D-Agent(Q) 的顶层组件，它为下游模块动态配置任务上下文和约束，确保设计、实现和评估之间的一致性。它沿着两个方向运行：

1. 理论方向：将先验假设、数据模式和输出协议编码为结构化 specification；
2. 经验方向：建立可验证的执行环境和用于回测的标准接口，将智能体与底层预处理和基础设施问题隔离开。

通过结合形式化定义和统一接口，该模块减少歧义，并提高各组件之间的协调效率。

我们将 Specification Unit 形式化为一个元组：

```text
S = (B, D, F, M)
```

其中，B 编码关于因子或模型的背景假设和先验知识；D 定义市场数据接口；F 表示期望输出格式，例如因子张量或收益预测；M 表示外部执行环境，例如基于 Qlib 的回测。

在这一形式化下，任一候选因子或模型 `fθ` 都必须满足：

```text
∀ x ∈ D, fθ(x) ∈ F
```

并且 `fθ` 能够在 M 中执行。这强制候选组件与标准化输入/输出结构兼容，并确保后续模块能够在共享操作上下文中与 `fθ` 交互，从而支持协作工作流的一致性和可复现性。实现细节见附录 E.1。

## 第 4 页

### 2.2 Synthesis Unit

Synthesis Unit 通过基于历史实验生成新的假设来模拟类似人类的推理。每个优化动作被定义为：

```text
at ∈ {factor, model}
```

对于当前动作 `at`，该单元会选择一部分相关历史实验来构造实验轨迹。第 t 个实验记为：

```text
et = {ht, ft}
```

其中 `ht` 是假设，`ft` 是来自 Analysis Unit 的对应反馈。系统会维护一组当前表现最好的解，记为 SOTA。基于此，历史假设集和反馈集分别定义为：

```text
Ht = {h1, ..., ht}
Ft = {f1, ..., ft}
```

然后提取动作条件子集：

```text
F_t^(a) = {f_i^a ∈ Ft | a = at ∨ ei ∈ SOTA(a)}
H_t^(a) = {h_i^a ∈ Ht | a = at ∨ hi ∈ SOTA(a)}
```

这些子集会被传入生成式随机映射 G。G 是 Research 的核心，模拟理论先验和经验反馈的综合，用于生成有效且新颖的假设：

```text
h_(t+1) = G(H_t^(a), F_t^(a))
```

在实践中，该模块依赖结构化模板和标准化格式，以确保生成的假设既可执行，又具有科学依据。例如，在因子生成任务中，`h_(t+1)` 不仅会包含最新反馈，还会包含当前市场条件和领域特定经济理论，从而保证该因子的有效性和可观测性。

为了促进多样性和渐进式细化，生成机制会根据性能反馈调整策略。如果 `F_t^(a)` 表示成功，那么下一条假设会增加复杂度或扩大范围；否则，它会进行结构调整或引入新的变量，从而形成一个想法森林。这种自适应机制使智能体能够在保持对经验结果敏感的同时探索新方向，支持迭代式且有效的策略开发。

最后，假设 `ht` 会被实例化为具体任务 `tt`，供下游 implementation 模块进行代码级实现。由于因子假设 `h_t^factor` 具有异质性并可能存在交互，因此可以被分解为多个子任务 `t_i^factor`。相比之下，模型假设具有结构一致性，因此会被映射为一个单一任务 `t^model`，负责执行完整建模和推理流程。

图 4：Co-STEER 工作流图。在因子开发场景中，它由两个主要模块组成：调度模块接收候选任务，并基于多种因素进行迭代排序；实现模块从先前代码执行结果中学习，构建细粒度、可迁移到不同任务的知识库。

### 2.3 Implementation Unit

Implementation Unit 负责将 Synthesis Unit 生成的可执行任务翻译为可运行代码。它构成 R&D-Agent(Q) 中复杂开发过程的核心。为了支持这一过程，我们设计了一个专门的智能体 Co-STEER，面向量化研究中的因子和模型开发。如图 4 所示，Co-STEER 整合了系统化调度和代码生成策略，以确保实现的正确性、效率和适应性。

在因子开发中，任务经常表现出结构性依赖。为此，我们引入引导式链式思维机制，以鼓励推理的可追踪性。具体而言，智能体会构造一个有向无环图：

```text
G = (V, E)
```

用于表示任务依赖，其中从任务 A 到任务 B 的一条边意味着由于知识流或复杂性，A 应先于 B 执行。随后推导出拓扑排序：

```text
πS = (t^(1), ..., t^(n))
```

以指导任务执行。调度是自适应的。前序执行的反馈会被持续整合以改进规划：如果某个任务反复失败，说明其复杂度较高，系统就会优先执行更简单的任务，以增强知识积累和执行成功率。

## 第 5 页

对于每个任务 `tj`，实现智能体 I 会根据任务描述和当前知识库生成对应代码 `cj`，即：

```text
cj = I(tj, K)
```

这一过程包括任务解析、代码合成与细化、执行和验证。智能体的目标是最大化累计实现质量：

```text
πI = arg max_π E[Σ_j=1^n RI(cj)]
```

其中 `RI(cj)` 评估代码 `cj` 的正确性和性能。知识库 K 在其中扮演核心角色，它会记录成功和失败的“任务-代码-反馈”三元组：

```text
K^(t+1) = K^(t) ∪ {(tj, cj, fj)}
```

其中 `fj` 表示执行任务 `tj` 后收到的反馈。通过知识迁移机制，实现智能体还可以基于当前反馈 `f^(t)` 从知识库中检索相似任务的解，从而提高新任务代码生成的效率和成功率：

```text
c_new = arg max_{ck∈K} similarity(t_new, tk) · ck
```

完整算法细节见附录 A.1。

这种反馈驱动的优化循环使 Implementation Unit 能够不断提升代码质量和效率，促进量化研究组件的快速、稳健开发。

### 2.4 Validation Unit

Validation Unit 评估 Implementation Unit 生成的因子或模型的实际有效性。对于因子，系统首先执行去重过程：通过计算新因子与已有 SOTA 因子库的相关性来过滤冗余信号。

给定拼接后的因子矩阵：

```text
F = [F_SOTA, F_new] ∈ R^(T × (M+N))
```

系统在每个时间切片中计算所有 `M × N` 对 SOTA 因子和新因子之间的 IC：

```text
IC_m,n^(t) = corr(F_SOTA,m^(t), F_new,n^(t))
```

其中 `(m, n)` 索引一个 SOTA-新因子对，t 索引一个时间切片。随后，这些 IC 值会跨时间平均；对于每个新因子 n，取其相对于所有 SOTA 因子的最大 IC：

```text
IC_max^(n) = max_m E_t[IC_m,n^(t)]
```

如果新因子的 `IC_max^(n) ≥ 0.99`，它会被视为冗余并被排除。因子过滤之后，剩余候选因子会与当前 SOTA 模型组合；如果还没有 SOTA 模型，则与基线模型组合，并通过 Qlib 回测平台进行评估。这使得性能可以在接近真实的市场条件下被评估。

对于模型，流程是对称的：每个候选模型会与当前 SOTA 因子集配对，并通过同一回测流水线评估。因此，Validation Unit 提供了一个集成且自动化的流程，支持在生产级市场仿真环境中对新组件进行标准化评估。

### 2.5 Analysis Unit

Analysis Unit 在 R&D-Agent(Q) 框架中既充当研究评估器，也充当策略分析师。在每一轮实验之后，它会对当前假设 `ht`、具体任务 `tt` 和实验结果 `rt` 进行多维度评估。如果该实验在动作类型 `at` 下被判定为优于 SOTA，其结果会被加入对应的 SOTA 集 `SOTA(at)`。

随后，该单元会诊断失败策略并生成有针对性的改进建议。反馈 `ft` 会被传递给 Synthesis Unit，用于指导未来假设的形成。值得注意的是，Analysis Unit 只基于当前实验的局部视角运行，而 Synthesis Unit 则维护跨完整实验历史的全局视角。二者的交互使闭环系统能够在短期响应能力和长期探索之间取得平衡，支持研究设计、策略实现、验证和深度分析之间的自动迭代。

在每轮分析之后，Analysis Unit 还会决定下一轮优先进行因子细化还是模型优化。为了最大化性能提升，这一决策被形式化为一个上下文双臂老虎机问题，并通过线性 Thompson sampling 求解，详细算法见附录 A.2。

具体而言，在每轮 t，系统观察一个 8 维性能状态向量：

```text
xt ∈ R^8
```

该向量编码当前策略的关键评估指标。动作空间为：

```text
A = {factor, model}
```

对应两个可能的优化路径。为了在上下文 `xt` 下评估每个动作的预期收益，作者采用线性奖励函数：

```text
r = w^T xt
```

其中 w 反映各指标的相对重要性。系统会为每个动作维护一个独立的贝叶斯线性模型，并使用高斯后验表示奖励系数的不确定性。在每一步，系统从每个后验中采样一个奖励向量，并计算对应期望奖励。系统会执行采样奖励最高的动作。观察到实际提升之后，所选臂的后验会被更新。

通过这种上下文 Thompson sampling 机制，R&D-Agent(Q) 能够自适应地平衡探索与利用，从而在迭代中实现稳健的性能提升。

作者在三种配置下评估 R&D-Agent(Q)：

1. R&D-Factor：将预测模型固定为 LightGBM，并从 Alpha 20 出发优化因子集；
2. R&D-Model：将输入因子集固定为 Alpha 20，并搜索更好的模型；
3. R&D-Agent(Q)：联合优化因子和模型组件。

注：Alpha 20 指从 Alpha 158 中选取的 20 个经过实证验证的因子，覆盖动量、价值、质量和成长。

### 基线

在因子层面，作者与 Alpha 101、Alpha 158、Alpha 360 和 AutoAlpha 比较。在模型层面，作者纳入了机器学习模型，包括 Linear、MLP、LightGBM、XGBoost、CatBoost、DoubleEnsemble；以及深度学习模型，包括 GRU、LSTM、ALSTM、Transformer、PatchTST、iTransformer、Mamba、TRA、MASTER 和 GATs。更多细节见附录 C.3。

### 评估细节

作者使用两类指标评估 R&D-Agent(Q)：

1. 因子预测指标：information coefficient，即 IC；IC information ratio，即 ICIR；rank IC；rank ICIR。
2. 策略表现指标：annualized return，即 ARR；information ratio，即 IR；maximum drawdown，即 MDD；Calmar ratio，即 CR。

作者采用基于预测收益排序的日频多空交易策略，并考虑持仓更新、持仓保留规则和现实交易成本。完整评估与实现细节见附录 C.4 和 C.1。

## 4 实验分析

### 主结果分析

表 1 报告了基线模型和 R&D-Agent 框架在 CSI 300 数据集上的表现，显示 R&D-Agent 在预测指标和策略指标上均一致优于所有基线。

1. R&D-Factor：因子优化。仅自适应优化因子空间时，R&D-FactorGPT-4o 和 R&D-Factoro3-mini 均超过静态因子库，例如 Alpha 158/360；其 IC 更高，最高达到 0.0497，ARR 也显著提升，最高达到 14.61%，同时使用更少的手工因子。这说明 R&D-Agent(Q) 中的动态假设细化和因子筛选能够产生比固定高维因子集更具信息量的信号。
2. R&D-Model：模型优化。在固定因子的模型优化中，R&D-Modelo3-mini 超过所有基线，并在 Rank IC 0.0546 和 MDD -6.94% 上取得最佳表现。机器学习模型明显落后，说明其在捕捉金融噪声和非线性模式方面存在局限。GRU、LSTM、Transformer 等通用深度学习结构虽然获得中等预测指标，但策略表现仍然较弱，说明特征提取与可交易收益之间存在缺口。令人意外的是，PatchTST、Mamba 等时间序列预测模型在两个方面表现都较弱，表明标准序列预测与股票市场动态之间存在根本错配。相比之下，TRA、MASTER 等专用股票预测模型在策略指标上较强，但预测能力较弱，体现出稳健性与精度之间的权衡。这些结果表明，由自动假设评估引导的自适应模型配置，比机器学习模型和手工设计的深度学习结构更稳健，也更具风险敏感性。
3. R&D-Agent(Q)：联合优化。通过联合优化因子和模型，R&D-Agent(Q)o3-mini 获得最高整体表现：IC 为 0.0532，ARR 为 14.21%，IR 为 1.74。这些提升大幅超过最强基线方法，例如 Alpha 158 和 TRA。结果说明，因子和架构的联合细化能够释放互补改进，使可扩展且一致的 alpha 建模成为可能。

量化策略传统上依赖资产定价理论中的人工构造因子，例如价值和动量。虽然这些固定信号具有可解释性，但它们通常缺乏适应市场状态变化的灵活性。

## 第 10 页

为克服这些限制，符号回归和遗传规划方法通过演化复杂的非线性表达式来自动化因子挖掘。滞后算子、带剪枝的算子变异等增强方法能够产生更多样且更有效的信号。强化学习方法则将因子分配重新表述为序列决策问题，直接优化 Sharpe 或 Calmar 比率。Andre 等人使用带 KL 正则的 Dirichlet 策略建模因子权重，从而实现稀疏且自适应的策略。然而，强化学习方法在市场状态转移下通常缺乏稳健性，例如 2020 年熔断事件，并且仍然难以解释。

在模型方面，ARIMA 和指数平滑等早期方法难以处理噪声大且高维的数据。经典机器学习方法，例如 SVM 和随机森林，提高了稳健性，但仍需要人工特征工程。LSTM 和 Transformer 等深度学习模型随后被用于捕获长期依赖和横截面依赖。在此基础上，专门的时间序列神经网络出现了。PatchTST 将输入切分为局部 patch，而 iTransformer 重新映射变量-token 关系以建模多变量结构。MASTER 等领域专用模型进一步融合市场层面动态，以提升金融预测。然而，因子流程和模型流程仍然彼此孤立，依赖专家且缺乏灵活性，这限制了其在波动市场中的可扩展性。

### 金融中的 LLM 驱动智能体

大语言模型由于具有强推理和抽象能力，为自动化金融研究提供了新的机会。近期工作探索了它们在从金融文本中提取预测信号、生成因子解释以及支持多模态市场分析方面的用途。与此同时，基于 LLM 的多智能体系统，例如 AutoGen 和 AutoGPT，也为复杂决策提供了协调框架。

在金融领域，FinAgent 和 TradingAgents 等系统使用基于角色的智能体来完成事件抽取或投资组合更新等子任务。然而，大多数现有工作关注狭窄子任务，并高度依赖语义信号，使其容易产生幻觉、难以解释且难以复现。此外，这些方法缺少因子-模型联合优化机制或工作流集成机制，从而限制了它们在真实量化系统中的有效性。

## 6 结论

作者提出 R&D-Agent(Q)，一个由 LLM 驱动的框架，用于量化金融中的协作式因子-模型开发。通过将研究拆解为模块化组件并整合基于 bandit 的调度器，该框架支持在固定计算预算下进行高效、自适应的迭代。实证上，R&D-Agent 在信号质量和策略表现两个方面都优于基线，并具有较强的成本效率和泛化性。其模块化设计也使其能够适应真实世界设置。

然而，当前框架完全依赖 LLM 内部的金融知识。未来工作可以增强数据多样性、引入领域先验，并支持对不断变化市场状态的在线适应。
