## 摘要

本文提出一种新的三阶段框架，在风险感知的多智能体系统中利用大语言模型（LLM），用于量化金融中的自动化策略发现。我们的方法通过以下方式应对传统深度学习模型在金融应用中的脆弱性：使用提示工程驱动的 LLM，从多样化金融数据中生成可执行的 Alpha 因子候选；实现基于多模态智能体的评估机制，在保持类别均衡的同时，根据市场状态和预测质量筛选因子；部署能够适应市场条件的动态权重优化。实验结果表明，相比既有基准，该策略在中国和美国市场环境中均表现稳健。本文将 LLM 的能力扩展到量化交易，提供了一个可扩展架构，用于金融信号提取和组合构建。整体框架在所有基准中均显著胜出，在 SSE50（2023 年 1 月至 2024 年 1 月）上取得 53.17% 的累计收益，显示出更优的风险调整后表现和下行保护能力。

注：SSE 50 指数跟踪上海证券交易所最具影响力的 50 只大盘蓝筹股。

## 1 引言

LLM 和多智能体系统的最新进展正在共同推动量化金融的转型。这种协同关系利用了 LLM 的文本理解与生成能力，并结合能够模拟市场动态的多智能体框架，从而形成更复杂的投资组合管理方法（Lee et al., 2020）。

LLM 已经从辅助分析工具演化为金融决策中的主动参与者（Luo et al., 2025c）。例如，BloombergGPT 在解析市场情绪和回答领域特定问题方面表现优异（Wu et al., 2023）。研究表明，LLM 能够通过结合价格趋势、新闻和财报语境来有效生成交易行为（Ding et al., 2023）。与此同时，多智能体系统通过去中心化交互为组合优化提供了有力方法。Multi-Agent Portfolio System 表明，由智能体管理的组合可以实现较好的分散收益，并提升风险调整后表现（Lee et al., 2025）。这些框架能够捕捉单智能体模型难以处理的复杂市场动态，例如信息共享和策略套利（Spooner and Savani, 2020）。这些技术的整合形成了更复杂的金融环境，其中由 LLM 增强的智能体表现出自适应行为。StockAgent 是这一思路的代表，它让 LLM 驱动的智能体模拟不同投资者画像并响应市场事件（Zhang et al., 2024a）。FinCon 等层级结构则把智能体组织成经理与分析师的关系，并通过自然语言沟通促进协作（Yu et al., 2024）。这种融合预示着智能化、分布式金融决策的未来，它将数据驱动学习与类人推理能力结合起来，以形成更稳健的投资策略（Yu et al., 2023b）。

Alpha 挖掘是发现金融市场中能够产生超额收益的交易信号的过程。我们识别出 Alpha 挖掘中的三个关键挑战：传统方法缺乏对动态市场的适应能力，具有刚性（Tang et al., 2025）；尽管机器学习取得进展，数据多样性与集成仍然困难（Cui et al., 2021; Yu et al., 2023a）；尽管预测（Xu and Cohen, 2018）和策略制定（Chen et al., 2019）已有进展，市场变化适应仍然困难。

我们的 LLM 驱动框架通过三个组成部分应对这些限制。第一，灵活 Alpha 挖掘使用 LLM 从金融文献中提取、分类并筛选 Alpha 因子，将其组织为动量、基本面、流动性等具有既定独立性的因子类别（Xu and Cohen, 2018）。第二，多智能体多模态市场评估在不同市场条件下进行严格回测，由专门智能体从多个角度评估因子有效性。第三，动态策略优化实现一个权重门控层，根据当前市场条件分配最优 Alpha 因子权重，从而保证策略开发的自适应性。

我们的方法将前沿机器学习技术与成熟金融领域知识结合，构建了一个稳健的跨学科框架，用于在多种资产类别中识别和优化 Alpha。该研究扎根于实证量化投资实践，连接了理论进展与组合管理中的实际应用。

本文主要贡献有三点。第一，提出一种使用 LLM 识别公式化 Alpha 因子的全新框架，利用 LLM 的探索能力，从多模态信息中建立可增量更新的 Alpha 工厂。第二，引入一种用于组合管理的多智能体方法，用于评估市场条件与 Alpha 因子之间的关系，使不同场景下的专门化评估成为可能。第三，整合机器学习和金融领域的先进技术，在无需人工干预的条件下推动稳健、自适应投资策略的发展。

所提出的框架在多种资产类别中展现了通用性，增强了实用性和实际有效性。为了支持后续研究并保证可复现性，作者公开了源代码：https://github.com/kouzhizhuo/Automate-Strategy-Finding-with-LLM-in-Quant-investment

## 2 问题形式化

本节为量化金融中的 Alpha 因子策略研究建立理论基础。我们构建了一个框架，用于处理三个相互关联的挑战：以数学方式形式化这些 Alpha；发展动态方法来生成种子 Alpha；定义并优化 Alpha 因子策略。我们的方法结合 LLM 与多智能体系统，以克服传统量化交易方法的限制。

全文使用一致的记号：在交易期 `t in {1, 2, ..., T}` 上观测 `n` 只股票，每只股票具有 `m` 个金融特征。股票 `i` 在时间 `t`、类别 `j` 中的 Alpha 因子记为 `alpha_ij^(t)`，对应权重为 `w_i`。时间 `t` 的市场条件表示为 `M(t)`，Alpha 因子的预测能力用信息系数（IC）衡量：

```text
IC = sigma(u, v)                                      (1)
```

较高的 IC 表明 Alpha 值与未来收益之间存在更强的预测关系。其中 `sigma(u, v)` 是预测 Alpha `u` 与实际未来收益 `v` 之间的相关系数。

### 2.1 Alpha 因子表示

第一个挑战是使用能够捕捉有意义金融信号的数学表达式来有效表示 Alpha 因子（Lo, 2007）。给定股票 `i` 在时间 `t` 的原始金融特征：

```text
X_i(t) = {X_i1(t), X_i2(t), ..., X_im(t)}
```

例如价格、成交量和波动率，我们通过两类算子定义 Alpha 因子。

截面算子 `f_cs`：这些算子处理单一时间期的数据，捕捉金融变量之间的即时关系：

```text
alpha_cs^(t) = f_cs(X_i(t))                           (2)
```

时间序列算子 `f_ts`：这些算子分析跨多个时期的数据，识别趋势和时间模式：

```text
alpha_ts^(t) = f_ts(X_i(t), X_i^(t-1), ..., X_i^(t-n)) (3)
```

股票 `i` 在时间 `t`、类别 `j` 中的种子 Alpha 定义为：

```text
alpha_ij^(t) = w_cs * f_cs(X_i(t))
             + w_ts * f_ts(X_i(t), ..., X_i^(t-n))    (4)
```

其中 `w_cs` 和 `w_ts` 分别是分配给截面部分与时间序列部分的权重。这种表示允许灵活组合不同金融信号，从而创建复杂且细致的 Alpha 因子。

### 2.2 Alpha 挖掘与选择

第二个挑战是传统 Alpha 挖掘方法的限制，这类方法通常无法适应不断变化的市场条件。我们提出一种动态选择方法，利用两个互补的评估机制来识别与当前市场条件最相关的 Alpha。

置信分数评估：评估每个 Alpha 因子的统计可靠性：

```text
theta_ij = E[ IC(alpha_ij^(t) | M(t)) ]                (5)
```

其中 `theta_ij` 表示 Alpha `alpha_ij` 的置信分数，`E[.]` 表示期望值。较高的置信分数意味着该 Alpha 在多种市场环境中表现更一致。

风险偏好评估：考察每个 Alpha 因子的风险特征：

```text
rho_ij = f_risk(alpha_ij^(t), M(t))                    (6)
```

其中 `rho_ij` 表示风险分数，`f_risk` 是评估该 Alpha 在不同风险场景下表现的函数。

最优种子 Alpha 集合通过同时考虑置信分数和风险评估来选择：

```text
alpha_ij = arg max_alpha_ij [w_c * theta_ij + w_r * rho_ij]  (7)
```

其中 `w_c` 和 `w_r` 分别是赋予置信分数和风险分数的权重，反映二者在选择过程中的相对重要性。

### 2.3 策略优化

第三个挑战是将所选 Alpha 组合成有效投资策略。最终 Alpha 策略定义为各类别最优 Alpha 的加权组合：

```text
alpha^(t) = sum_{j=1}^{k} w_j * alpha_ij               (8)
```

其中 `w_j` 表示分配给类别 `j` 的权重，`k` 是 Alpha 类别总数。这些权重会根据当前市场状态动态调整，以在管理整体组合风险的同时最大化策略表现。该优化步骤完成了整个框架，将原始金融数据转化为能够适应变化市场环境的稳健交易策略。

## 3 方法

### 3.1 框架概览

我们的框架由三个相互连接的组件组成（图 1）：种子 Alpha 工厂（SAF）、多智能体决策和权重优化。初始阶段使用 LLM 分析并分类多模态金融研究文档，构建全面的 SAF。LLM 处理多样化数据集的能力，使其能够创建一组稳健的种子 Alpha，并将它们划分到相互独立的类别中，这与既有金融 Alpha 挖掘原则一致（OpenAI, 2023）。

第二阶段实现一个多模态、多智能体评估流程，纳入不同风险视角，提升策略在不同市场条件下的适应性。该阶段会产生适合当前市场状态和风险偏好的优化 Alpha 集。最后阶段使用深度学习方法优化所选 Alpha 的权重，构造整体一致的策略。

该框架的动态架构支持持续改进：随着新研究出现和市场条件演化，SAF 可以进行增量更新。这种适应性保证策略随时间保持相关性和稳健性。该方法具有通用性，可以应用于全球任何结构化市场，并有效复现和增强专业投资研究流程。

### 3.2 基于 LLM 的种子 Alpha 生成

第一阶段实现一个基于 LLM 的筛选和分类流程，用于处理与 Alpha 相关的研究。我们使用 GPT-4o 模型在多样化金融研究语料上执行这些任务。初始数据集包含 11 篇文档，覆盖 Alpha 挖掘研究的理论与应用方面（见附录 A.2）。通过该流程，系统生成 9 个不同类别，共 100 个种子 Alpha。该方法增强了模型从金融研究中提取复杂细节和关系的能力，形成更稳健、更多样的 SAF。

输出是一组结构化种子 Alpha，按照动量、均值回归、基本面分析等不同金融领域分类。每个类别包含具体的 Alpha 名称以及由 LLM 分析得到的可执行公式（见附录 A.3）。该结构化输出构成后续处理阶段的基础。

### 3.3 多模态多智能体评估

第二阶段通过多模态和多智能体系统，对 Alpha 因子进行全面评估与选择。系统包含五类多模态数据（详见附录 A.4）：文本、数值、视觉、音频和视频输入。多智能体架构包含两个智能体：置信分数智能体（CSA）和风险偏好智能体（RPA）。

被选中的 Alpha 因子使用历史市场数据进行严格回测，关键评估指标包括 IC（Goodwin, 1998）和夏普比率（Sharpe, 1994）：

```text
Sharpe Ratio = E[R(alpha^(t)) - R_f] / sqrt(Var[R(alpha^(t))])   (9)
```

其中 `R(alpha^(t))` 表示策略收益，`R_f` 表示无风险利率。我们开发了一个基于类别的 Alpha 选择算法（详见附录 A.5）来自动化选择流程。该算法根据置信分数系统地识别并选择来自不同类别的 Alpha，确保在所有类别中选择满足置信阈值的因子，同时维持类别多样性。

图 1 概述了策略生成的三个组件：使用 LLM 构建的种子 Alpha 工厂、多智能体决策系统，以及用于整体策略的权重优化方法。其中 CS 表示置信分数，RP 表示风险偏好。

### 3.4 权重优化

最后阶段使用三层 MLP，通过把历史 Alpha 计算结果映射到未来收益来优化所选种子 Alpha 的权重（Chen and et al., 2020）。该架构由输入层、隐藏层和输出层组成：输入层处理每日 Alpha 值；隐藏层包含 10 个使用 ReLU 激活的节点；输出层为单节点，用于收益预测。

训练期间，网络使用反向传播和梯度下降来最小化损失函数，该函数度量预测收益与实际收益之间的差异。我们使用独立验证集来保证模型泛化能力并防止过拟合。DNN 通过隐藏层处理输入数据，使用学习到的权重和偏置进行转换，并通过输出层的权重、偏置和激活函数生成最终输出。

该方法建立了一个稳健框架，用于基于历史 Alpha 值预测未来收益，证明了深度学习技术在优化 Alpha 权重和提升投资策略表现方面的有效性。原文中的算法说明给出了完整框架的形式化描述，展示了从多模态数据处理、多智能体评估到最终权重优化的逻辑流程。

## 4 实验

本文研究目标是开发一个全面的 LLM 驱动 Alpha 挖掘框架，该框架无需人工干预即可运行。它具有处理多模态信息和适应不同市场条件的独特能力。为了验证框架有效性，作者开展了一系列实验。

### 4.2 多模态知识提取与自适应 Alpha 发现

我们实现了一种提示架构（图 2），将多模态市场信息纳入 LLM，用于全面知识提取和种子 Alpha 选择。该架构整合了文本金融情绪数据、数值型公司财务报表和视觉交易图表，以提供整体市场分析（Luo et al., 2025b）。上下文分析机制会根据主导市场趋势和行业表现动态调整参数。

实验验证表明，该框架可以适应不同市场条件。在案例 1 中，模型分析 2023 年 1 月至 2023 年 12 月的 SSE50 数据，选择了价格动量、RSI、MACD 等动量和成交量类指标。相反，在案例 2 中，当处理 2022 年 1 月至 2022 年 12 月的时间窗口时，模型优先选择了波动率和经济类因子，包括 ATR、布林带和毛利指标。

这些结果确认了框架通过有效整合多模态数据来动态适应变化市场条件的能力。这种适应性使框架能够识别适合市场状态的 Alpha，从而增强策略在多样化市场环境中的稳健性。

## 5 相关工作

量化投资中的公式化 Alpha 是系统性、基于规则的策略，它们通过利用特定市场模式和无效性来产生超额收益（Kakushadze, 2016）。这些策略使用多种方法，包括通过结构和数值变异生成新 Alpha 的遗传规划（Cong et al., 2021）、使用互信息作为适应度度量的增强型时间序列算子（Lin et al., 2019），以及用于更复杂预测的算法图（Cui et al., 2021）。机器学习方法使用 LSTM（Hochreiter and Schmidhuber, 1997）和 Transformer（Vaswani et al., 2017）等神经网络架构，而 XGBoost（Chen and Guestrin, 2016）和 LightGBM（Ke et al., 2017）等决策树模型则具有可解释性优势。近期研究关注整合非标准数据源，REST（Xu et al., 2021b）和 HIST（Xu et al., 2021a）是代表性工作。

通用领域 LLM 的发展激发了人们对金融 LLM（Fin-LLMs）的兴趣，但这一专门领域仍处于早期阶段（Novy-Marx, 2015; Yang et al., 2023; Zhao et al., 2023）。LLaMA（Touvron et al., 2023）、BLOOM（W. and et al., 2023）和 Flan-T5（W. and et al., 2022）等开源 LLM 提供了灵活性，但可能弱于专有模型。经过金融领域微调的 LLM 表现出更强的领域理解能力，但其生成表现也表明仍需要更好的领域专用数据集（Lewis and et al., 2020; Koa et al., 2024; Wen et al., 2025）。

多模态 LLM 在投资语境中展现了显著潜力：它们可以处理多样化数据类型（L et al., 2023; Luo et al., 2025a），开发降低市场波动影响的策略（K et al., 2024），并分析文本数据以衡量投资者情绪（Zhao et al., 2024）。多智能体 LLM 系统通过利用大规模数据集解释财务报告和市场情绪（Zhang et al., 2024b）、模拟多种市场场景（Talebirad and Nadiri, 2023），以及并行测试多样化策略（Wang et al., 2024），增强了市场分析能力。实现这些系统也带来了有关透明度、问责和偏差缓解的重要问题（Yu and et al., 2024; Mundhenk et al., 2021）。

## 6 结论

本文提出一种新的量化投资框架，将 LLM 与多智能体架构整合起来，以应对传统方法的不稳定性。该系统从多模态金融数据中生成多样化 Alpha 因子，构建风险校准的交易智能体，并使用深度学习机制根据市场条件动态加权智能体。

实验结果确认了该框架在中国和美国市场中的有效性。该框架在关键金融指标上相对于最先进的 Alpha 生成方法和基准指数表现出显著优势。本文成功将 LLM 能力扩展到量化交易，创建了一个可扩展、自适应的金融信号提取架构，该架构能够在无需人工干预的情况下，在多种市场状态中有效运行。

## 7 局限性

该框架存在若干重要限制。第一，系统有效性依赖输入文档质量，可能延续其中固有偏差（Deb et al., 2017; Ashok et al., 2018）。第二，LLM 生成的 Alpha 有时缺乏人类分析师所具备的金融直觉，可能产生理论上成立但实践中不可行的因子（Tuarob et al., 2017）。第三，多智能体评估方法假设市场条件与 Alpha 表现之间的历史关系会持续存在，而这一假设在市场状态切换期间可能较为脆弱。最后，验证工作主要聚焦股票市场，跨资产适用性仍需要额外实证研究。

未来研究应通过探索专家混合（MoE）架构以提升学习效率（Masoudnia and Ebrahimpour, 2014）、自适应智能体架构、迁移学习方法（Wang et al., 2023）、相关监管要求（Han and Xi, 2020）以及计算高效实现等方向来处理这些约束。

### A.3 生成种子 Alpha 工厂

该分类体系将量化交易信号组织为动量、均值回归、波动率、基本面、流动性、质量、成长、技术和宏观经济指标等类别。每个类别都通过特定数学实现瞄准不同市场现象。动量因子识别持续趋势，均值回归信号检测市场过度反应，波动率指标量化价格离散程度，基本面因子评估公司估值。框架还包括衡量交易活动的流动性指标、衡量运营效率的质量指标、衡量财务扩张的成长指标、从价量模式中得到的技术指标，以及反映更广泛经济条件的宏观经济信号。所提供的数学公式使研究者能够实现多样化、低相关的 Alpha 因子，以支持稳健量化交易策略。

| 类别 | 名称 | 公式 |
|---|---|---|
| Momentum | 价格动量 | `(CLOSE - DELAY(CLOSE, 14))` |
| Momentum | 成交量动量 | `(VOLUME - DELAY(VOLUME, 14))` |
| Momentum | RSI 动量 | `(RSI - DELAY(RSI, 14))` |

### A.5 基于类别的 Alpha 选择

算法 1 描述了一种用于量化投资策略 Alpha 选择的系统方法，它采用基于类别的方法来确保多个金融因子之间的分散化。该流程运行在结构化的 Alpha 类别集合 `C` 上，每个类别代表不同市场现象，例如动量、均值回归或波动率。对于每个类别，算法通过 `SelectBestAlphas` 函数识别更优的 Alpha 因子，该函数应当评估历史表现指标。

创新点在于后续的双智能体评估系统：RiskPreferenceAgent 评估每个 Alpha 的风险特征，ConfidenceScoreAgent 评估其历史表现的统计稳健性。这两个互补评估使用权重参数 `w_r` 和 `w_c` 融合，得到综合最终分数。只有超过预设置信阈值 `X` 的 Alpha 才会进入最终选择集 `A`。这种方法确保所得 Alpha 组合同时具备类别分散性和个体信号质量，可能在提升风险调整后收益的同时，降低对特定市场状态或因子衰退的暴露。

算法 1：基于类别的 Alpha 选择

```text
输入：类别 C = {C1, ..., Cm}，每个 Ci 包含一组 Alpha；置信阈值 X
1: 初始化所选 Alpha 集合 A <- empty
2: for 每个类别 Ci in C do
3:     Ai <- SelectBestAlphas(Ci)
4:     for 每个 alpha in Ai do
5:         risk_score <- RiskPreferenceAgent(alpha)
6:         confidence_score <- ConfidenceScoreAgent(alpha)
7:         final_score <- w_r * risk_score + w_c * confidence_score
8:         if final_score > X then
9:             A <- A union {alpha}
10:        end if
11:    end for
12: end for
13: return A
```

### A.6 动态 Alpha 策略构建

算法 2：整体框架算法

```text
输入：多模态金融数据 D，市场条件 M(t)，股票 S，置信阈值 tau
输出：优化后的 Alpha 策略 alpha(t)

阶段 1：SAF
1:  初始化空的种子 Alpha 工厂 F <- empty
2:  for 每个文档 d in D do
3:      filtered_content <- LLM.Filter(d)
4:      categories <- LLM.Categorize(filtered_content)
5:      for 每个类别 c in categories do
6:          seed_alphas <- LLM.GenerateAlphas(c)
7:          F_c <- F_c union seed_alphas
8:      end for
9:  end for

阶段 2：多智能体评估
10: 初始化所选 Alpha 集合 A <- empty
11: for 每个类别 c in F do
12:     for 每个 alpha_ij in F_c do
13:         theta_ij <- ConfidenceScoreAgent(alpha_ij, M(t))    # 统计评估
14:         rho_ij <- RiskPreferenceAgent(alpha_ij, M(t))       # 风险评估
15:         score_ij <- w_c * theta_ij + w_r * rho_ij           # 综合分数
16:         if score_ij > tau then
17:             A_c <- A_c union {alpha_ij}
18:         end if
19:     end for
20:     if A_c is not empty then
21:         alpha_c* <- arg max_{alpha_ij in A_c} score_ij      # 选择该类别最优 Alpha
22:         A <- A union {alpha_c*}
23:     end if
24: end for

阶段 3：权重优化
25: 初始化 MLP，架构为 {|A|, 10, 1}                         # 输入层、隐藏层、输出层
26: X_train <- ComputeHistoricalAlphas(A, S, t_start, t_end)
27: y_train <- FutureReturns(S, t_start + 1, t_end + 1)
28: w <- TrainMLP(X_train, y_train)                           # 学习最优权重
29: for 每只股票 S_i in S do
30:     alpha_i(t) <- sum_{j=1}^{|A|} w_j * alpha_ij(t)        # 计算复合 Alpha
31: end for
32: return alpha(t) = {alpha_1(t), alpha_2(t), ..., alpha_n(t)}
```

### A.7 种子 Alpha 选择示例提示词

1. 训练集包括：

- 财务报告：SSE 50 中 50 家上市公司的 6 个季度财报（2021 年 1 月至 2022 年 6 月）。
- 因子分析数据：37 个因子（2021 年 1 月至 2022 年 6 月），分为动量、均值回归、波动率、基本面、质量、成长、技术、宏观经济等组。使用的指标是 IC。

2. 目标：学习 2022 年至 2023 年前四个季度的财务报告表现，与 2022 年最后一个季度中 37 个因子各自因子分析数据（IC）之间的关系。

3. 当给定测试集（2023 年前四个季度表现）时：

- 选择将在 SSE 50 最后一个季度中表现最好的因子。
- 为每个选中的 Alpha 因子提供置信分数和风险偏好。

4. 选择标准：

- 如果无法发现财务报告与 IC 之间的关系，则选择每组中 IC 值最高的 Alpha 因子。
- 为了验证市场信息差异，如果无法发现财务报告与 IR 之间的关系，则选择 IR 值最高的 Alpha 因子。

### A.8 投资组合构建方法

作者的投资方法使用 top-k/drop-n 选择框架进行每日组合重构。在每个交易时段，所有证券按照其 Alpha 值排序，Alpha 值是预期超额收益的量化指标；随后选择排名前 `k` 的股票纳入组合。该方法瞄准信号最强的证券，可能利用短期市场无效性。作者对所选证券采用等权配置，将资本均匀分配给排名最高的候选股票。这种做法具有分散化优势，也符合作者对 Alpha 信号的看法：它们主要提供方向性指示，而不是精确收益预测。

为了优化交易成本和操作效率，作者将组合每日换手限制为最多 `n` 只证券。该约束在保持组合与当前 Alpha 信号一致和减少交易摩擦成本之间取得平衡。在第 4.4 节实验中，作者基于广泛回测设定 `k = 13`、`n = 5`。该配置形成一种组合集中度，在分散化和信号稀释之间取得平衡，同时将每日换手限制在约 38%。这一水平在交易成本模型中表现出有利特征，并代表了信号利用和实施成本之间的有效权衡。

## 每章内容总结

### 摘要

论文提出一个三阶段 LLM 驱动的自动量化策略发现框架：先生成可执行 Alpha 因子，再由多模态多智能体评估筛选，最后通过动态权重优化形成组合策略。核心结果是在 SSE50 2023 回测中获得 53.17% 累计收益，并优于多种基准。

### 第 1 章：引言

本章说明 LLM 与多智能体系统在量化金融中的结合趋势，并指出传统 Alpha 挖掘存在刚性、数据集成困难和市场适应不足等问题。作者提出通过 LLM Alpha 工厂、多智能体市场评估和动态策略优化来解决这些问题，并总结了三项主要贡献。

### 第 2 章：问题形式化

本章给出数学定义：将 Alpha 表示为截面算子和时间序列算子的组合，用 IC 衡量预测能力，并把 Alpha 选择建模为置信分数与风险偏好的加权优化。最终策略是各类别最优 Alpha 的动态加权组合。

### 第 3 章：方法

本章介绍完整方法流程。第一阶段用 GPT-4o 从金融研究文档中生成并分类种子 Alpha；第二阶段使用 CSA 和 RPA 两类智能体，对多模态输入下的 Alpha 进行置信和风险评估；第三阶段用三层 MLP 学习 Alpha 权重，生成最终策略。

### 第 4 章：实验

本章验证框架效果。作者在 SSE50、CSI300 和 SP500 上进行实验，使用 OHLCV、VWAP、财报、市场图表等数据。结果显示，所选 Alpha 的 IC 高于原始 SAF，综合策略在 SSE50 回测中显著跑赢机器学习方法、LLM 方法和指数基准，并在跨市场、跨时间验证中保持稳健。

### 第 5 章：相关工作

本章回顾公式化 Alpha、机器学习 Alpha 挖掘、金融 LLM、多模态 LLM 和多智能体金融系统。作者将本文定位为把 LLM、因子生成、多模态信息和多智能体评估统一到自动化量化策略发现中的工作。

### 第 6 章：结论

本章总结框架贡献：系统能够从多模态金融数据生成多样化 Alpha，构建风险校准交易智能体，并通过深度学习动态加权。实验表明，该方法可以在无需人工干预的情况下，在不同市场状态中实现较强超额表现。

### 第 7 章：局限性

本章指出主要限制：输入文档质量会影响结果并可能带来偏差；LLM 生成的 Alpha 可能缺乏实践金融直觉；多智能体评估依赖历史关系持续存在的假设；验证主要集中在股票市场，跨资产泛化仍需进一步研究。
