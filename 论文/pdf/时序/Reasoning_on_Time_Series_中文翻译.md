## 摘要

尽管大语言模型已经被用于生成可解释的股票预测，但它们主要关注文本报告分析，而不是历史价格数据分析，后者也被称为技术分析。这个任务具有挑战性，因为它需要在不同领域之间切换：股票价格的输入和输出位于时间序列领域，而推理步骤应当以自然语言表达。在本文中，我们提出 Verbal Technical Analysis（VTA，语言化技术分析），这是一个新框架，将语言化推理与潜在推理结合起来，生成既准确又可解释的股票时间序列预测。

为了在时间序列上进行推理，我们将股票价格数据转换为文本注释，并使用基于反向均方误差（MSE）的奖励目标来优化推理轨迹。为了从文本推理中生成时间序列输出，我们用基于推理得到的属性来条件化时间序列骨干模型的输出。在美国、中国和欧洲市场的股票数据集上的实验表明，VTA 达到了最先进的预测准确率；同时，行业专家评估的结果也显示，其推理轨迹在各项指标上表现良好。代码地址：https://github.com/chen-jan/VTA。

## 1 引言

随着大语言模型（Large Language Models, LLMs）的兴起，金融分析正成为一个越来越受欢迎的应用方向。这一方向涵盖了多类任务，包括金融问答（FinQA）、投资决策以及市场预测。现有方法大多主要利用 LLM 强大的自然语言能力来分析金融报告，或对社交文本进行情绪分析（见表 1），却忽视了对股票价格数据的可解释分析，而这类数据很可能包含对金融从业者有用的信息。

来自一般时间序列领域的现有解决方案尚不足以完成这一任务。已有关于时间序列推理的研究持续报告称，LLM 难以对原始时间序列输入进行推理。与此同时，时间序列 LLM 往往依赖于重编程嵌入空间，这虽然可以生成时间序列输出，却牺牲了语言化推理能力，而后者是可解释金融分析的一项基本要求。最接近的工作是 TimeCAP，它通过辅助信息为序列提供上下文来生成解释。然而，它的推理轨迹来自外部数据，并且预测输出是分类标签，而不是完整的时间序列轨迹。

与其他时间序列数据不同，金融时间序列包含专家广泛研究的内在可解释信号，也就是技术分析。我们利用这些信号对金融时间序列进行语言化分析，并生成可解释的股票预测。

使用 LLM 进行时间序列推理主要受到三类挑战的限制。首先，当前 LLM 在时间序列预测方面能力有限。一些工作通过修改嵌入空间来生成时间序列输出，但这样会牺牲可解释性，因为 LLM 会失去其自然语言能力。其次，从更高层面看，**当前 LLM 尚未被证明具备通过时间序列上的语言化推理来产生准确预测的能力**。这要求模型能够以无监督方式理解如何最好地分析时间序列数据中的预测信号。第三，LLM 的推理轨迹还需要被转换成时间序列输出，才能生成有用的股票预测。LLM 通常是在下一词元预测目标上微调的，直接使用时间序列输出并不会产生最佳预测，这一点我们也通过实证进行了验证。

表 1：相关工作的比较。我们的工作为从业者提供了一种新的可解释金融信号，并对如何让时间序列预测变得可解释提供了一些洞见。

| 类别 | 模型 | 领域 | 输入 | 输出 |
|---|---|---|---|---|
| 金融 LLM | Fin-R1、Fino1 | 金融问答 | 金融报告 | 文本答案 |
| 金融 LLM | FinMem、FinCon | 投资决策 | 文本、表格、音频 | 二元结果（买入/卖出） |

| 时间序列 LLM | TimeCAP | 时间序列推理 | 时间序列 + 辅助信息 | 分类 + 推理 |
| 本文 | Verbal Technical Analysis（VTA） | 时间序列推理（金融） | 金融时间序列 | 时间序列 + 推理 |

为解决这些问题，我们提出三项关键贡献。首先，我们提出 Verbal Technical Analysis（VTA）框架，它将一个骨干时间序列模型（我们称之为“潜在思考”）与一个推理 LLM（称为“语言化推理”）结合起来，生成可解释的股票时间序列预测。该框架结合了最先进时间序列模型强大的模式处理能力与 LLM 强大的推理能力，从而生成既准确又可解释的预测。

其次，为了在时间序列上进行推理，股票时间序列数据会被转换为文本注释，作为 LLM 输入。随后，我们通过一种修改后的 Group Relative Policy Optimization（GRPO）目标来优化推理轨迹，该目标使用基于反向均方误差（MSE）的奖励评分，我们称之为 Time-GRPO。

第三，为了从推理轨迹中生成时间序列输出，我们用基于推理得到的属性来条件化时间序列模型生成的输出。

为了展示 VTA 的有效性，我们在已有股票基准以及美国、中国和欧洲市场的额外股票数据上进行了广泛实验。结果显示，我们的模型在预测准确率上达到最先进水平，同时具有可解释性。此外，行业专家评估表明，推理轨迹在文献中的多种评估指标上得分较高。最后，为了证明模型的实际能力，我们基于预测长度构建 Markowitz 投资组合，并展示由 VTA 预测形成的投资组合在投资指标上同样表现良好。

## 2 相关工作

**金融大语言模型。** 大语言模型的兴起推动了其在金融领域应用的研究。最早的工作主要开发通用金融 LLM，例如 BloombergGPT 和 FinMA，它们通过在多个下游任务的大规模金融语料上微调而来。随后，研究开始处理 LLM 在金融领域中的特定挑战。例如，金融问答（FinQA）相关工作关注如何教会 LLM 分析金融报告，这需要模型具备阅读结构化财务表格并从复杂文档中提取洞见的能力。用于投资决策的 LLM 通常利用多智能体系统来处理投资决策中的不同部分，包括但不限于文档分析、记忆、风险控制等。用于金融预测的 LLM 试图预测市场将向哪个方向变化。通常，这类工作会分析文本来源，以理解公司的情绪或财务健康状况。我们的工作处于这一领域之中，学习从金融时间序列数据中生成可解释的前瞻性信号，而这可能有益于上述所有应用。

**时间序列大语言模型。** 同时，利用 LLM 处理时间序列领域问题的研究也在增长。时间序列 LLM 借助 LLM 的大规模参数和稳健模式识别能力，并通过微调将其用于时间序列预测任务。然而，这些方法通常会修改 LLM 的嵌入空间，使其失去原本的语言推理能力。

也有一些工作探索了 LLM 对时间序列数据进行推理的能力。研究发现，语言模型在零样本时间序列推理上“非常糟糕”；而使用潜在编码器进行微调则在时间序列描述生成推理上展现出一些有希望的早期结果。最接近的时间序列推理工作来自 TimeCAP，它通过使用辅助时间序列信息为输入时间序列提供上下文来进行预测。它通过搜索相似历史上下文生成解释，并以文本形式输出分类标签预测。我们的工作沿着这一研究方向继续推进，通过利用金融时间序列内部的预测信号来生成可解释的时间序列预测，并提供一些关于 LLM 在时间序列数据上进行推理能力的洞见。

## 3 语言化技术分析

Verbal Technical Analysis（VTA）框架如图 1 所示。它包含三个组成部分：

1. 在时间序列推理中，我们教会 LLM 对时间序列输入进行语言化推理。这通过一个文本注释器提取有用指标，并通过我们提出的 Time-Series Group Relative Policy Optimization（Time-GRPO）方法实现。
2. 在时间序列预测中，我们训练一个骨干预测模型，它能够更好地学习时间序列数据中的复杂低层模式。
3. 在联合条件训练中，时间序列预测以推理属性为条件，并且模型同时在有条件预测和无条件预测上进行训练。

图 1：Verbal Technical Analysis（VTA）框架。我们首先教会 LLM 对时间序列数据进行推理。推理输出用于条件化一个时间序列预测模型，以生成具有相似属性的预测。这会得到带有可解释推理轨迹的预测结果。

### 3.1 问题形式化

我们考虑基于长度为 T 个交易日的历史窗口来预测短期未来股票价格的任务。令：

```text
X = {x_{t-T+1}, x_{t-T+2}, ..., x_t}
```

其中输入向量由开盘价、最高价、最低价、成交量、收盘价和复权收盘价组成，即：

```text
x_t = [o_t, h_t, l_t, v_t, c_t, p_t]
```

我们的目标是生成输出：

```text
Y = {v, y}
```

它由语言化推理轨迹 `v` 和未来 `T'` 个交易日的价格轨迹组成：

```text
y = {p_{t+1}, p_{t+2}, ..., p_{t+T'}}
```

### 3.2 时间序列推理

为了教会 LLM 对时间序列输入进行推理，我们使用文本注释器来提取有助于预测的可解释信号。LLM 使用这些指标在没有任何监督数据的情况下对时间序列进行推理并做出预测。这是通过我们提出的 Time-Series Group Relative Policy Optimization（Time-GRPO）方法实现的，该方法结合了多阶段强化学习流程和修改后的 GRPO 目标。

时间序列输入首先被转换为文本注释，这些注释包括其统计信息（例如均值、最小值和最大值）以及金融技术指标（例如移动平均、动量等）。形式化地表示为：

```text
X' = f(X)
```

其中 `f` 包含注释函数，`X'` 表示注释后的数值。附录 B 提供了本文使用的金融技术指标完整列表，以及它们的描述和计算方法。

**训练目标。** 使用时间序列 `X` 及其注释 `X'`，我们构造一个提示 `q`，并让 LLM 通过语言化推理预测即将到来的时间序列。LLM 的目标是生成输出 `o`，其中包含序列预测 `ŷ_θ` 和语言化推理轨迹 `v̂_θ`。形式化地，我们将所有任务提示的集合记为 `Q`，将一组生成输出记为：

```text
O = {o_1, o_2, ..., o_G}
```

随后，时间序列推理 LLM 策略 `π_θ` 会在所有组上使用如下 Time-GRPO 目标进行优化：

```text
L_time-grpo(θ) =
E_{q~Q,{o_i}_{i=1}^G~π_{θ_old}(O|q)}
  1/G * Σ_{i=1}^G (
    min(
      π_θ(o_i|q) / π_{θ_old}(o_i|q) * A_i,
      clip(π_θ(o_i|q) / π_{θ_old}(o_i|q), 1-ε, 1+ε) * A_i
    )
    - β D_KL(π_θ || π_ref)
  )
```

其中：

```text
D_KL(π_θ || π_ref)
= π_ref(o_i|q) / π_θ(o_i|q)
  - log(π_ref(o_i|q) / π_θ(o_i|q))
  - 1
```

`ε` 和 `β` 是超参数。`A_i` 表示 LLM 策略的优势，它来自与每组生成输出 `O` 相关的一组奖励 `{r_1, r_2, ..., r_G}`：

```text
A_i = (r_i - mean({r_1, r_2, ..., r_G}))
      / std({r_1, r_2, ..., r_G})
```

我们使用了先前工作中的格式奖励，要求模型始终在 `<think>` 和 `</think>` 标签之间执行思考过程。

理想情况下，生成的推理轨迹也应最大化时间序列预测的期望准确率。为实现这一点，我们将均方误差（MSE）分数作为额外奖励：

```text
r_MSE(θ) = 1 / (λ · ||ŷ_θ - y||_2^2)
```

其中 `λ` 是超参数。由于奖励分数需要被最大化，因此这里使用了反向 MSE。

**训练流程。** 按照 LLM 微调文献中的既定实践，Time-GRPO 使用多阶段流程来微调时间序列推理 LLM。

第一阶段是冷启动阶段。由于不存在“金标准”监督数据，该阶段用于生成初始训练样本，并由 `L_time-grpo` 目标引导。经验上，我们发现这一阶段的预测性能不会显著提高，但该过程能够让我们为下一阶段生成训练数据，用以微调基础模型。

第二阶段侧重于教会模型生成更有效的推理。这通过拒绝采样实现：我们只保留那些能带来较低均方误差（MSE）预测的推理轨迹。为了保证训练样本的一致性，我们还会按照不同股票和时间段对样本分桶，并在每个桶中筛选 MSE 处于最低 10% 分位的样本。随后，模型通过监督微调（SFT）在这些筛选后的样本上训练。

第三阶段针对技术分析任务中的最佳预测性能优化模型。由于模型已经在上一阶段学会了对时间序列数据进行推理，本阶段的目标是搜索能够最大化预测时间序列期望准确率的最佳推理策略。在该阶段，模型同样使用 `L_time-grpo` 目标进行优化。

### 3.3 时间序列预测

为了执行时间序列预测，我们采用基于 LLM 的时间序列模型。已有工作表明，LLM 强大的上下文建模能力可以被有效适配到时间序列预测任务中。关键技术之一是对齐时间序列分布和语言分布，使模型能够理解时间序列数据的上下文（例如上涨、下跌、平稳等）。对于我们的骨干模型，我们将一个 LLM 重新用于跨模态微调。

在这一步中，我们首先将时间序列输入 `X` 输入嵌入层，然后通过多头注意力层，得到投影后的时间词元 `X_time`。接下来，我们观察到相似词在 LLM 嵌入空间中通常彼此接近；而对于非文本任务，保留聚类中心足以降低训练成本。为此，我们执行主成分分析（PCA）来提取主词嵌入 `D̂`。

随后，我们将投影时间词元 `X_time` 和主词嵌入 `D̂` 输入多头交叉注意力层。这使我们能够在预测模型的嵌入空间中对齐时间词元和词嵌入，从而得到对齐后的跨模态文本词元：

```text
X_text = Softmax(QK^T / sqrt(C)) V
where
Q = X_time W_q,
K = D̂ W_k,
V = D̂ W_v
```

其中 `W_q`、`W_k` 和 `W_v` 分别是多头注意力层中查询、键和值的投影矩阵，`C` 是每个注意力头的嵌入维度。`X_text` 指对齐后的文本词元。

接下来，投影时间词元 `X_time` 与对齐文本词元 `X_text` 会通过连续的 LLM transformer 块。为了引导模态对齐，在时间分支和文本分支的每个 transformer 块之后，嵌入都会通过一个投影层，并通过特征正则化损失进行匹配。这保证文本表征在每一层都与时间动态保持一致。形式化地，给定时间分支和文本分支中第 `n` 个 transformer 块的输出 `F_time^n` 和 `F_text^n`，我们将特征正则化损失定义为：

```text
L_feature = Σ_{n=1}^N γ^(N-n)
            sim(φ_text^n(F_text^n), φ_time^n(F_time^n))
```

其中 `γ^(N-n)` 是缩放超参数，`sim(·, ·)` 是用于保证嵌入相似性的 L1 正则化损失，`φ_time^n` 与 `φ_text^n` 分别是时间分支和文本分支中的投影层。

在 transformer 块的末端，特征会经过最后的全连接层，生成基于时间和基于文本的输出 `ŷ_time` 与 `ŷ_text`。二者也通过 L1 损失进行匹配：

```text
L_output = sim(ŷ_time, ŷ_text)
```

我们提取基于时间的输出 `ŷ_time`，并将其记为时间序列预测 `ŷ_φ(X)`。

### 3.4 联合条件训练

图 2：联合条件训练组件。

单独来看，时间序列预测流程是一个黑箱模型，因为 LLM 块的嵌入空间已经被修改，导致模型只输出时间序列。为了保留时间序列预测的可解释性，我们用推理模型产生的输出来条件化时间序列预测。同时，为了保留预测准确性，我们会对模型进行微调，使其同时优化有条件预测和无条件预测。

在这一步中，我们首先使用时间序列推理策略 `π_θ` 提示生成推理输出 `o`。接下来，我们从生成的时间序列 `ŷ_θ` 中提取描述性属性类别 `c`（即其最大值、最小值和均值），这些属性会通过联合条件训练来条件化时间序列预测（见图 2）：对于每个标签，我们将其与时间序列预测模型输出的时间序列预测 `ŷ_φ(X)` 拼接。这些输入会通过独立的线性层进行微调，然后通过一个投影层聚合，生成条件化的时间序列预测，记为 `ŷ_ψ(X, c)`。

最后，我们使用一个单一神经网络来同时参数化有条件模型和无条件模型。通过以预定义概率 `p_uncond` 随机将 `c` 设置为无条件类别标识符 `∅`，无条件和有条件流程会被同时训练。随后，模型使用与真实序列 `y` 的 MSE 损失进行微调：

```text
L_forecast(φ) = E_{X,y,c}[ ||ŷ_ψ(X, c̃) - y||^2 ]
```

其中：

```text
c̃ ~ c, with probability 1 - p_uncond
c̃ ~ ∅, with probability p_uncond
```

在推理阶段，我们的预测是有条件预测与无条件预测的组合：

```text
ŷ = s · ŷ_ψ(X, c) + (1 - s) · ŷ_θ(X)
```

其中 `s` 是表示引导尺度的超参数，用于控制推理引导的强度。

## 4 实验

**数据集。** 我们在多个数据集上对 Verbal Technical Analysis（VTA）模型进行了广泛评估。第一个数据集是 ACL18 StockNet 数据集，它包含 88 只美国股票的历史价格数据，这些股票按主要行业中市值排名前 8-10 的公司选取，用以代表各行业。该数据集覆盖 2012-01-09 到 2017-01-09 期间。它是一个标准股票预测基准，已在多项工作中被评估。

为了进一步展示模型的泛化能力，我们还从美国、中国和欧洲市场收集了额外股票数据进行测试。为确保选择无偏，我们从知名指数中选择股票，即道琼斯指数、富时中国 A50 指数和 EURO STOXX 50。对于这些数据集，我们在 2024-01-01 到 2025-01-01 的时间段上进行测试。

**基线。** 我们与 12 种最先进的时间序列方法进行比较：Transformer、Reformer、Informer、Autoformer、DLinear、FiLM、Crossformer、MICN、LightTS、TimesNet、TSMixer 和 Non-Stationary Transformer。我们还与两个基于 LLM 的时间序列模型比较：TimeLLM 和 CALF。这些模型不可解释，其中两个 LLM 也会修改嵌入空间以进行预测。

对于可解释模型的评估，我们与推理 LLM 进行比较：GPT-4.1 mini 和 DeepSeek-R1。为此，我们提示这些模型通过在时间序列输入上进行推理来生成时间序列预测。

**实现细节。** VTA 模型中使用的所有 LLM，包括推理模型和用于时间序列预测的 transformer 块，均使用低秩适配（LoRA）训练。输入和输出长度 `T` 与 `T'` 都设置为 10，这在时间序列工作中被视为短期预测。技术分析通常用于短期股票交易。

对于推理模型，我们使用 Qwen2.5-7B-Instruct 作为基础模型。对于预测模型，我们使用 GPT-2 作为基础模型。对于超参数，我们将条件概率 `p_uncond` 设为 0.3，将引导尺度 `s` 设为 0.1。关于实验设置和计算资源的更多细节见附录 A。

**性能比较。** 表 2 报告了预测结果。我们可以观察到以下几点：

- 仅推理的 LLM（即 GPT-4.1 mini、DeepSeek-R1）表现并不十分强，原因可能是它们没有针对时间序列预测进行微调。然而，它们仍然能够超过部分微调后的时间序列模型（例如 Transformer、DLinear），这说明通过对时间序列输入进行语言化推理来进行预测具有一定有效性。
- 在时间序列基线中，最大性能提升来自那些按趋势和季节性分解数据的模型（即 FiLM、MICN、Autoformer 和 TimesNet）。这可能归因于股票价格的特征，因为股票价格常常受到长期和短期商业周期的影响。另一个表现良好的模型是 Non-stationary Transformer，这可能归因于股票价格数据的非平稳行为。
- 时间序列 LLM 能够超过非 LLM 模型的性能。这类模型通常会将 LLM 的内部词嵌入与时间序列嵌入对齐，以执行时间序列预测。LLM 的内在知识可能帮助模型理解股票数据的特征，从而更好地捕捉预测模式。
- 我们提出的 VTA 模型在股票预测中，在 MSE 和 MAE 上都展示出最佳性能。VTA 明确结合了内部（潜在）理解与外部（语言化）推理。实证提升表明，整合这两种技术可能有益于时间序列预测。除了提高准确性之外，VTA 模型还能为其预测生成可解释推理轨迹，而大多数基线模型不具备这一点。

1. 对抗式：向技术指标数值添加对抗噪声。
2. 移除信息：在提示中强制 LLM 在推理时不使用某些指标。

**推理质量。** 为了评估推理轨迹的质量，我们参考 LLM 可解释性相关工作，为我们的任务设计了一组相关指标。每条推理轨迹及其对应的时间序列预测都以 1（差）到 5（优秀）的尺度评分。标准定义如下：

- 清晰性：推理是否以结构化方式清晰、简洁地解释其分析。
- 深度：推理是否充分结合明确的金融或技术指标（例如 MACD、RSI、布林带、EMA）来有意义地支持其结论。
- 准确性：金融指标是否被精确解释并以技术性方式描述。
- 连贯性：推理在逻辑上是否一致且组织良好，确保分析与结论之间清晰对齐。
- 相关性：所选指标是否直接且有效地关联到给出的股票价格预测。

使用这些指标，我们调查了 25 位具有金融市场分析专业经验的行业专家，他们的背景来自 JPMorgan、UBS、Evercore、Allianz Global Investors 等机构。对于每位受访者，我们展示了 VTA（本文）、GPT-4.1 mini 和 Deepseek-R1 的模型输出，包括预测和文本推理。受访者不知道哪个模型产生了哪个输出，并会看到 15 个随机选取的样本用于评估。

**投资组合优化。** 为证明 VTA 的实际能力，我们也在真实投资设置中评估模型。由于模型会生成多步预测，我们能够在预测长度上构建最大化收益并最小化波动率的投资组合。这是通过对 10 天预测执行 Markowitz 优化实现的。投资组合每日再平衡，使用预测收益及其协方差矩阵。

评估时，我们将其与由表现前 5 的时间序列模型和所有 LLM 基线形成的类似投资组合进行比较。投资组合会在常见投资指标上比较，例如 Sharpe 比率。所用投资组合指标解释如下：

- 收益率：衡量给定期间内投资组合价值的百分比变化，表示整体盈利能力。
- 波动率：刻画收益随时间变化的离散程度，较高波动率反映更大的波动和不确定性。
- 最大回撤：表示投资组合价值从峰值到谷值的最大下降，突出评估窗口内观察到的最严重亏损。
- Sharpe 比率：通过比较超额收益与收益波动率来评估风险调整后表现，数值越高表示风险承担效率越高。

## 6 结论

在本文中，我们处理了对金融时间序列数据进行语言化推理的任务。该任务具有挑战性，因为它需要在股票价格数据所属的时间序列领域与推理步骤所属的自然语言领域之间切换。为解决这一问题，我们提出 Verbal Technical Analysis（VTA）框架，该框架结合语言化推理和潜在推理来生成可解释的时间序列预测。该框架使用我们的 Time-GRPO 方法微调推理模型，并基于推理属性对预测进行条件化。我们进行了广泛实验，发现 VTA 能够达到最先进的预测准确率，同时生成高质量推理轨迹。

基于本文的观察，我们提出两个可能的未来方向。第一，将更多股票特征纳入 VTA 模型，例如趋势和季节性、非平稳行为。第二，改进推理与预测之间的对齐方式，可能通过使用来自图像条件控制的更高级技术实现。

## A 额外实验细节

### A.1 模型和训练超参数

本节总结用于训练 Verbal Technical Analysis（VTA）模型的关键超参数。所有大语言模型（LLM）组件均使用 Unsloth 框架训练，该框架支持 4-bit 量化和低秩适配（LoRA）。Group Relative Preference Optimization（GRPO）的实现遵循 Hugging Face TRL 库中概述的原则。

脚注链接：Unsloth R1 reasoning 博文：https://unsloth.ai/blog/r1-reasoning；Hugging Face TRL GRPO Trainer 文档：https://huggingface.co/docs/trl/main/en/grpo_trainer。

**时间序列推理。** 推理模型基于 Qwen2.5-7B-Instruct 开发，使用由 GRPO 和监督微调（SFT）组成的多阶段训练流程。最大序列长度通过 `max_seq_length` 参数控制，推理时温度设为 0.2。

LoRA 使用特定的 `lora_rank`，并作用于关键模块，例如注意力投影（`q_proj`、`k_proj`、`v_proj`、`o_proj`）以及前馈层（`gate_proj`、`up_proj`、`down_proj`）。在用于格式学习的初始和最终 GRPO 训练阶段，学习率为 `5 × 10^-6`，训练两个 epoch。每个设备处理的 batch size 为 4，并使用两个梯度累积步骤。对于 GRPO，每个提示生成四个结果，提示和补全的总长度上限为 500 个词元。奖励基于目标格式遵循程度和预测准确性。

对于 SFT 数据生成，我们采用拒绝采样机制，从总共 100 个桶中选择 MSE 排名前 10% 的示例。随后通过 SFT 进行推理增强，学习率为 `2 × 10^-4`，训练两个 epoch。在这里，每设备 batch size 降为 1，同时将梯度累积步数增加到 4。

**时间序列预测。** VTA 模型的预测组件改编自 GPT-2，并使用固定的 10 天输入和输出序列长度（记为 `T` 和 `T'`）。该组件训练 20 个 epoch，学习率为 `1 × 10^-4`，batch size 为 16。架构包含 6 个 GPT 风格 transformer 层，由 `gpt_layers` 参数定义。

LoRA 配置为 rank 8、缩放因子 `lora_alpha` 32、dropout 率 0.1。联合条件训练采用无条件训练概率 `p_uncond = 0.30`，引导尺度 `s = 0.1`。此外，还利用预测序列的统计性质（即最小值、最大值和均值）纳入对齐损失。

### A.2 计算资源

所有实验均使用 4 张 NVIDIA A5000 GPU（每张 24 GB VRAM）进行。完整推理模型训练包括冷启动强化学习、监督微调和奖励引导的 GRPO：使用 Unsloth 的 LoRA 微调实现并设置 `gpu_memory_utilization=0.5`（每个进程约需 21 GB VRAM）时，LLaMA 3.1-8B 约需 120 GPU 小时，Qwen 2.5-7B 约需 100 GPU 小时，Qwen 2.5-3B 约需 60 GPU 小时。

一旦生成推理轨迹，下游预测运行会显著更高效。对于单只股票，使用约 1000 个训练点和 250 个测试点训练一个预测模型，在单张 GPU 上约需 3 分钟（使用约 2.7 GB VRAM）。在完整 StockNet 数据集上运行一次约需单张 GPU 4.5 小时。

| 指标 | 描述 | 公式 |
|---|---|---|
| 简单移动平均（SMA） | 通过平滑一段时间内的价格数据来识别趋势 | `SMA = (1/n) Σ_{i=1}^n Price_i` |

| 平均趋向指数（ADX） | 使用方向性运动衡量趋势强度 | `ADX = 100 × EMA(|DM+ - DM-|) / (DM+ + DM-)` |
| 布林带 | 使用移动平均周围的标准差衡量波动率 | `Upper Band = MA + k · σ`; `Lower Band = MA - k · σ` |

## C 主要结果的统计显著性

为了评估模型性能实验中相对于第二佳模型的差异（`MSE_0 = 0.06737`，`MAE_0 = 0.17380`）是否具有统计显著性，我们使用不同随机种子运行模型 `n = 10` 次，并在备择假设“我们的模型误差低于第二佳模型误差”下执行单样本、单侧 Student t 检验。令 `x̄` 和 `s` 分别表示 10 次运行中该指标的样本均值和样本标准差：

```text
t = (x̄ - μ_0) / (s / sqrt(n))
```

其中 `μ_0` 是第二佳模型的误差。对于 `p < 0.05`，我们拒绝原假设。

表 6：相对于第二佳模型的单样本、单侧 t 检验结果。

| 指标 | x̄ | s | t | p（单侧） |
|---|---:|---:|---:|---:|
| MSE | 0.06661 | 0.00054 | -4.42 | 8.3 × 10^-4 |
| MAE | 0.17081 | 0.00047 | -20.04 | 4.5 × 10^-9 |

两个检验都得到 `p << 0.05`，说明相对于第二佳模型的误差降低具有统计显著性。为完整起见，我们报告不同随机种子上的完整分布：

```text
MSE = 0.06661 ± 0.00054
MAE = 0.17081 ± 0.00047
```

其中为均值 ± 标准差，`n = 10`。我们选择单次最佳运行（`MSE = 0.06594`，`MAE = 0.17008`）用于所有后续评估。

## H 投资组合的金融分析

为了评估我们投资组合收益的稳健性，我们应用了金融领域广泛使用的标准绩效归因模型。这些模型允许我们将可以由共同风险暴露解释的收益，与可能反映策略特定价值的收益区分开来。

- 资本资产定价模型（CAPM）：一种基线模型，将投资组合收益与整体市场收益关联起来。它提供了一种衡量策略在调整市场风险（beta）之后是否产生超额收益（alpha）的方法。
- Fama-French 多因子模型：CAPM 的扩展，纳入了额外风险因子，例如公司规模、价值相对成长、盈利能力、投资模式和动量。这些因子刻画了市场暴露之外已被充分记录的收益驱动因素。

这些模型使我们能够评估结果是由一般市场和因子暴露解释，还是展示了超越既有基准的增量表现。按照行业实践，我们使用 CAPM 和 Fama-French 六因子模型，对由 VTA 方法形成的投资组合进行深入绩效归因研究。

### H.1 CAPM 回归模型

对于 CAPM，我们将以下模型应用于投资组合和市场的日收益：

```text
(R_VTA,t - R_f,t) = α + β · (R_market,t - R_f,t) + ε_t
```

其中：

- `(R_portfolio,t - R_f,t)`：第 `t` 天我们投资组合的超额收益。
- `(R_market,t - R_f,t)`：第 `t` 天市场基准的超额收益。
- Alpha（`α`）：回归截距，表示投资组合收益中无法由市场变化解释的部分。
- Beta（`β`）：回归斜率，衡量投资组合相对于市场的系统性风险。
- Epsilon（`ε_t`）：第 `t` 天的误差项。

正且统计显著的 alpha 表明策略更优，而 alpha 为 0 表示它与基准 CAPM 方法具有相同表现。此外，我们还报告方法相对于基准的 R-squared，它显示收益变化中有多少可由 CAPM 解释。对于投资者来说，较低的 R-squared 更理想，因为这表明交易信号相关性较低，从而降低投资组合的特异性风险。

我们使用各地区代表性市场指数，将每日投资组合收益回归到超额市场收益上。以下是四个数据集上的结果总结。

CAPM 回归结果为理解我们策略的风险调整后表现提供了有用的初步诊断。在全部四个数据集上，策略都表现出正的年化 alpha，这说明收益超过了仅由整体市场暴露所预测的水平。然而，统计显著性只在 China A50 数据集中达到，其中 alpha 既高（+53.91%）又显著（`p = 0.008`）。在其他市场中，尽管 alpha 仍为正，但更高的 p 值表明系统性超额表现的证据较弱。

表 10：CAPM 回归结果。

| 数据集 | 使用的市场指数 | Beta（β） | 年化 Alpha（α） | Alpha p 值 | R-squared |
|---|---|---:|---:|---:|---:|
| dowjones 30 | Dow Jones Industrial（DJI） | 0.6745 | +3.41% | 0.701 | 44.04% |
| stocknet | MSCI World（ACWI） | 0.6312 | +10.12% | 0.198 | 36.28% |
| ftse china a50 | FTSE China A50 ETF（2822.HK） | 0.3562 | +53.91% | 0.008 | 26.72% |
| eurostoxx 50 | EURO STOXX 50（STOXX50E） | 0.2804 | +15.44% | 0.120 | 15.93% |

0.28 到 0.67 范围内的 beta 值表明存在中等市场暴露。这说明策略并非完全市场中性，但也不是简单跟踪指数走势。这与我们使用短期技术预测而不是宏观驱动持仓相一致。

R-squared 值范围为 15.93% 到 44.04%，显示相当一部分收益变化无法由 CAPM 解释，尤其是在欧洲和中国市场。这指向一种有意义的特异性收益生成能力，与模型在传统市场风险之外提取有用交易信号的设定一致。

### H.2 Fama-French 六因子模型

我们进一步使用 Fama-French 六因子模型评估表现。该模型在 CAPM 基础上增加五个因子：市场、规模、价值、盈利能力、投资和动量：

```text
R_p - R_f =
α + β_1(R_m - R_f) + β_2 · SMB + β_3 · HML
  + β_4 · RMW + β_5 · CMA + β_6 · WML + ε
```

表 11：Fama-French 六因子回归结果。

| 数据集 | 年化 Alpha（α） | Alpha p 值 | R-squared |
|---|---:|---:|---:|
| dowjones 30 | +0.18% | 0.985 | 38.77% |
| stocknet | +9.57% | 0.213 | 39.37% |
| ftse china a50 | +73.40% | 0.001 | 13.81% |
| eurostoxx 50 | +13.67% | 0.184 | 12.35% |

Fama-French 六因子分析提供了更细粒度的绩效视角。尽管所有数据集中的 alpha 仍为正，但其显著性有所不同，从 China A50 中的 0.001（非常显著）到 0.985（不显著）不等。缺乏显著性的一种可能原因是我们测试数据集的周期较短（1 年）。

R-squared 值范围为 12.35% 到 39.37%，表明即使在考虑 CAPM 之外更广泛的一组风险因子之后，仍有相当一部分收益变化无法解释，这是一件好事。在我们的工作中，技术分析通常被设计用于短期优化，捕捉短暂的动量、反转或基于成交量的效应。由于这种短期关注点，我们的模型并不预期会与 CAPM 或 Fama-French 这类通常以数月或数季度尺度评估的长期经济模型紧密对齐。

总体而言，结果表明，我们的方法确实为 CAPM 和 Fama-French 六因子之外提供了一定互补价值，可作为一种可解释的前瞻性投资组合信号。
