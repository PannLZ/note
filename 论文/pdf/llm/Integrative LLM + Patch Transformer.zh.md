## 摘要

大语言模型的最新进展提升了语义抽取能力。然而，现有方法仍然难以从冗长、重复的金融文本中提炼真正会影响市场的信号；同时，简单拼接或单向交叉注意力往往无法捕捉文本语义与价格动态之间的双向依赖关系。本文提出一种包含分层摘要与协同注意力的多模态框架，用于联合学习金融新闻和历史价格，从而预测股票趋势。该框架包括三个核心组成部分。首先，分层 LLM 逐步精炼文本，去除冗余，并抽取与市场波动最相关的多层次线索。其次，基于补丁的单通道 Transformer 并行建模价格序列和文本流，在保留各模态时间结构与上下文结构的同时降低注意力复杂度。最后，协同注意力机制动态对齐并强化跨模态特征，得到更稳健的联合表征。实验结果表明，本文方法在 CMIN-US 上取得 67.01% 的方向预测准确率和 0.346 的 Matthews 相关系数，在 CMIN-CN 上取得 70.24% 的准确率和 0.293 的 Matthews 相关系数。消融实验进一步证明，分层摘要与协同注意力的结合显著提升了多模态预测性能。

## 1. 引言

人工智能已经成为金融领域不可或缺的技术，支撑着股票价格趋势预测、智能投顾、风险管理等关键应用。传统方法主要依赖历史价格序列和经典统计模型，例如支持向量机、加权神经网络等，但这些方法通常难以捕捉由非结构化信息驱动的快速市场动态。因此，将金融新闻、社交媒体情绪、公司披露等另类数据源整合进预测模型，已经成为重要方向。然而，如何有效抽取并融合这些异构信号，仍然是一个主要挑战。

文本信息在金融市场中的作用日益重要。金融新闻、分析报告和社交媒体评论等文本数据不仅反映市场情绪，也揭示基本面信息，为股票趋势预测提供了新的数据维度。已有研究将文本信息整合进股票预测模型，例如利用情绪分析工具揭示推文信息与股票收益之间的相关性，利用因果分析连接金融新闻与股价波动，或构建多模态 LSTM 模型以实现在线新闻文本和股价数据之间的交互。还有研究分析了文本表示、机器学习模型和新闻平台对基于文本挖掘的股票预测的影响。

尽管文本信息在股票预测中具有巨大潜力，从大规模且多样化的金融文本中精准抽取关键信息仍然是金融科技领域的难题。为了解决这一问题，许多研究采用自然语言处理技术分析金融文本。例如，有研究用 BERT 深度表示社交媒体文本并结合公司关系数据以增强股票趋势预测，也有研究将 BERT 与生成对抗网络结合预测股票价格，或将 BERT 情绪分析结果与宏观经济指标结合进行预测。虽然 BERT 等预训练模型在文本理解方面展现出巨大潜力，但传统 NLP 技术在处理海量复杂金融文本时仍有明显局限，难以捕捉深层语义和细微上下文关系，限制了关键信息的准确抽取与利用。

近年来，大语言模型的发展给 NLP 带来了革命性进步，也为提升股票预测模型的精度和适应性提供了新机会。例如，有研究利用 ChatGPT 分析金融新闻并为股票赋予买入分数，量化未来趋势；也有研究将预训练 LLM 与序列知识引导提示结合，自动识别影响股票波动的因素，并将历史价格数据转换为文本格式来预测股票走势；还有研究用预训练 LLM 构建去噪新闻编码器，从金融新闻中抽取有价值信息，以提升多股票走势预测。

但是，股票数据的特点给 LLM 应用带来特殊挑战。首先，股票相关数据通常包含大量文本信息，包括金融新闻、财报、社交媒体评论和分析师报告。这些文本高维、异构且时效性强，需要模型快速处理并抽取关键信息。其次，现有 LLM 通常存在输入长度限制，例如 mT5 的输入限制为 512 个 token。同时，由于这些模型基于 Transformer 架构，计算复杂度为 \(O(n^2)\)，处理长序列时资源成本会显著上升。最后，长文本可能导致模型无法准确聚焦关键时间点或关键事件，从而影响预测性能。

为解决上述问题并发挥 LLM 的文本理解优势，本文提出一种增强方法。具体而言，本文使用预训练的任务相关 LLM，并引入分层摘要技术从金融文本中抽取关键信息。原始文本被切分为离散块，并经过迭代式精炼。该过程不仅可以深度捕捉文本内部语义与细微上下文关系，进而准确识别影响股票波动的关键因素，也缓解了传统方法在精确信息抽取方面的不足。

在利用 LLM 挖掘文本信息后，另一个挑战是如何为预测任务融合多模态数据。传统融合方法，如简单特征拼接或加权求和，通常以直接方式组合不同类型的数据，并且额外参数调节较少。这类方法虽然便利，但存在明显局限: 它们难以充分捕捉不同模态之间的复杂关系和潜在交互，无法完全发挥各模态的互补优势，从而限制模型性能和灵活性。为此，研究者引入了基于注意力的融合方法。注意力方法可以动态评估各模态对预测任务的贡献，并捕捉复杂依赖与潜在交互，但在局部特征捕捉和计算效率方面仍然不足。

针对这些问题，本文采用单侧 Transformer 架构结合补丁技术，对文本和价格数据进行建模，并提出一种新的文本-价格协同注意力模块。该模块同时关注文本特征和价格特征，捕捉两种模态之间的深层关联与互补信息，从而克服传统注意力机制在局部特征抽取和计算效率方面的局限。

## 2. 相关工作

人工智能在股票交易中的应用已经成为重要研究方向，涵盖投资组合优化、市场预测、金融新闻情绪分析，以及融合多种方法的混合框架。其中，AI 驱动的股票趋势预测已经取得了先进性能。本节回顾两个关键领域的最新进展: 股票趋势预测和深度学习时间序列预测。

### 2.1 股票趋势预测

由于金融市场具有复杂性、随机性和动态演化特征，股票价格趋势预测仍然是一个基础而困难的问题。为更好利用异构和非结构化数据源，近期研究主要集中在三个互补方向。

**多模态信息处理。** 研究表明，将金融新闻文本、情绪分数、数值指标等异构模态融合，可以显著提升股票趋势预测性能。有研究将金融新闻文本与因果增强矩阵结合，用于捕捉趋势预测中的跨模态交互；也有研究设计多源聚合分类器，将数值市场指标与新闻驱动的情绪分数融合；还有研究通过场景检测框架提取看多和看空专家观点，从而提升预测准确率。另一些工作将 LSTM 和 Transformer 结合，用分钟级价格序列、投资者情绪和 COVID-19 指标建模制药行业，获得更好的准确率、F1、精确率和召回率，并通过 Granger 因果和脉冲响应分析发现强因果关系。还有研究提出自适应多模态框架，用 RCNN 和 RNN 层处理新闻、情绪和技术指标中的复杂时间依赖，在不同市场中表现稳健。尽管这些方法有效，高频成分和分布式异常仍可能扰动分解或融合过程，限制鲁棒性。

**特征选择。** 有效的特征选择对于提升股票市场预测至关重要，因为它可以识别并保留最有信息量的预测变量。已有研究提出多过滤器选择流水线结合深度生成模型来改善未来价格走势预测，也有研究将变异系数选择器嵌入神经网络以减少特征冗余并提升性能。还有研究将多种特征选择算法应用于数百个交易特征，并整合投资者情绪指标，再输入多个深度学习模型。综述研究指出，基于相关性的准则、随机森林、主成分分析和自编码器是常用且有效的方法。这些工作表明，谨慎选择少量高影响特征可以降低计算成本、缓解过拟合，并提升性能和可解释性。

**模型架构。** 图神经网络模型因能够捕捉复杂的股票间关系和时间依赖而受到关注。例如，GC-CNN 从股票相关图中抽取图卷积特征，再用于 CNN 预测；多模态多尺度动态图卷积网络可以对齐数值与文本模态，抽取多尺度时间表示，并学习动态时空关系；多图卷积对抗框架可以从历史数据生成多个相关图以提升预测鲁棒性；动态超图时空网络使用 GRU 和超图注意力学习高阶股票关系。尽管这类方法强大，但它们在节点和边上存在二次复杂度，并需要图结构与时间序列输入的精确时间对齐。

总体而言，从多模态融合、高级特征选择到图结构建模，这些方法显著提升了从结构化与非结构化金融数据中抽取预测信号的能力。然而，在联合建模细粒度时间动态、保持计算效率以及实现稳健多模态对齐方面，仍然存在挑战。

### 2.2 时间序列预测中的深度学习

在多变量时间序列预测中，近期工作主要集中在三个方向。

**基于注意力的编码器-解码器架构。** 带注意力的编码器-解码器模型可以自适应关注最有信息量的输入片段，并在解码过程中动态选择上下文，从而增强长程依赖建模。相关工作包括结合线性模型简单性和非线性协变量建模能力的 TiDE，采用 Bi-LSTM 编码器-解码器联合学习上下文和时间注意力向量的方法，以及概率时序潜变量自编码器等。这些方法在水质预测、电池荷电状态估计、大坝位移预测、混沌多步时间序列预测等领域取得了强实证表现。

**PatchTST 和混合模型。** “补丁”技术将长序列划分为更短的可学习窗口，可以缓解灾难性遗忘和冗余噪声。为降低计算成本并更好捕捉局部模式，研究者提出了多种 PatchTST 变体和混合模型，例如结合 Transformer 与 CNN 的 PatchTCN、用于 ECG 异常检测的 PatchTST 扩展、结合季节感知 PatchTST 重构和多任务学习的超短期负荷预测模型、多尺度 patch-mixing 框架 MSPatch、多分辨率 patch-based Fourier 图谱网络等。补丁模型还被用于光伏功率预测和海浪高度预测，在多个任务中优于 Informer、LSTM 和 NeuralProphet 等模型。

**用于时间序列的大语言模型。** LLM 不仅可用于生成高质量摘要，也可增强时间序列表征。受 NLP 成功启发，研究者将预训练 LLM 与补丁重编程结合用于预测，也将时间序列编码为 token 序列，利用 LLM 建模多模态分布并通过文本占位符处理缺失数据，从而实现零样本推理。还有工作利用 LLM 从文本和价格数据中抽取洞察，得到更具解释性的预测；通过微调预训练语言或图像模型而不修改核心自注意力或前馈层，展示了在不同时间序列任务中的有效性。Instruct-FinGPT 等模型也说明了指令微调 LLM 在金融情绪分析中的潜力。

虽然上述方法推动了各自领域发展，但尚无现有框架能够同时实现以下三点: 第一，对文本和价格时间序列进行分层语义抽象与细粒度融合；第二，在严格计算预算下进行多尺度时间建模；第三，对极端市场冲击保持韧性。为弥补这一空白，本文提出一种新的多模态预测架构，通过两阶段分层摘要管线利用预训练 LLM 的语义能力进行信息抽取。该架构使用基于补丁的注意力编码器联合表示交织的文本和价格序列，随后使用协同注意力融合模块实现深层跨模态交互。基准数据集上的实验表明，本文框架在预测准确率和鲁棒性方面优于先进方法。

## 3. 提出的方法

### 3.1 模型概览

本文提出一个四阶段框架，用于分层抽象文本内容、编码细粒度时间模式，并深度融合语义与价格动态，以实现稳健的股票趋势预测。以 Apple Inc. (AAPL) 为例，某一交易日的新闻和相应价格序列由多模态框架处理。框架包含四个顺序模块。

1. **分层摘要。** 分层摘要通过先将全部文本来源，例如新闻文章、报告、社交媒体评论等，切分为一小时区间，来提炼显著信息并抑制微观噪声。每个小时批次由预训练 LLM 压缩成简短摘要。随后，这些摘要按时间顺序拼接，并由同一个 LLM 再次处理，生成统一的日度概要。最后，从日度概要中抽取稠密 embedding 向量，得到该日文本内容的紧凑表示。

2. **嵌入与对齐模块。** 该阶段通过交叉注意力机制连接文本模态和数值模态。文本 embedding 和归一化价格序列特征分别作为查询、键和值输入交叉注意力块，整合语义和金融信号。对齐后的序列随后被划分为重叠时间补丁。每种模态都由带多头自注意力的单向 Transformer 编码器处理这些补丁，以捕捉局部时间依赖。可训练线性投影将文本和价格补丁 embedding 映射到共享潜在空间，模态特定自注意力层进一步精炼内部结构。

3. **协同注意力融合模块。** 这里通过对称双流注意力架构捕捉双向跨模态依赖。在一个流中，文本 embedding 查询价格的键和值；在另一个流中，价格 embedding 查询文本的键和值。每个流都产生跨模态交互的注意力加权表示。两个输出沿特征维拼接，并通过线性投影恢复原 embedding 维度。残差连接将该投影与初始 embedding 合并，层归一化稳定融合张量，从而为下游分类统一模态特定上下文与跨模态上下文。

4. **分类模块。** 融合后的特征张量被展平成特征向量，并输入全连接层与 sigmoid 激活函数，输出价格上涨的概率分数。

本文框架使用固定的任务特定 LLM 进行两阶段摘要，即先小时级再日级，从而在无需微调开销的情况下保持稳定语义抽象。只有编码、融合和分类层被端到端训练，使时间编码器能够基于融合反馈迭代精炼特征。通过将摘要与模型训练解耦，并将优化重点放在跨模态整合上，本文设计实现了高效信息抽取和全面时间洞察，在波动市场条件下获得更高预测准确性和鲁棒性。

### 3.2 分层摘要

**算法 1: 分层摘要**

输入: 原始文档 \(\{D_t\}_{t=1}^T\)，小时级提示 `Prompt_hour`，日级提示 `Prompt_day`

输出: 日度摘要 embedding \(x_e\)

1. 小时级摘要。
2. 对 \(t = 1\) 到 \(T\):
3. \(S_t \leftarrow LLM(Prompt_{hour}, D_t)\)
4. 循环结束。
5. 拼接小时级摘要。
6. \(S_{concat} \leftarrow concat(S_1, \ldots, S_T)\)
7. 日级摘要。
8. \(S_{day} \leftarrow LLM(Prompt_{day}, S_{concat})\)
9. 抽取 embedding。
10. \(x_e \leftarrow Embed(S_{day})\)
11. 返回 \(x_e\)。

本文的分层摘要模块基于信息融合理论和多分辨率信号处理原则，采用多阶段摘要策略，以缓解大规模异构文本语料中的信息冗余和序列长度限制。具体而言，在信息瓶颈原则指导下，本文实现小时级摘要流程，在每个一小时时间间隔内识别并抽取信息量最高的句子，从而在抑制无关噪声的同时最大化保留关键事件语义。随后，日级摘要将这些小时摘要进一步提炼为粗粒度的日度概要，在局部细节与全局结构之间取得平衡，这正是多分辨率分析的特点。最后，为尊重 LLM 的输入长度限制和计算预算，后续模块只接收摘要 embedding，而不是完整文本序列，从而显著减少 token 处理开销，并保证与后续编码器的可扩展集成。

为适应 LLM 在处理大量股票相关文本时的输入长度和计算限制，本文采用分层摘要策略。股票相关文档通常包含超出常规序列长度阈值的细粒度细节。因此，原始文本被划分为小时级片段，每个片段覆盖固定时间间隔内的股票相关内容。这种切分在减少计算开销的同时保留必要的上下文和时间关系。在 AAPL 示例中，作者选择若干个价格显著波动的日期，展示分层摘要如何捕捉市场事件与波动之间的相互作用，例如财报发布、全球情绪变化和监管新闻。小时级摘要保留盘中动态，例如对新闻的即时反应；日级摘要强调每次显著波动背后的总体驱动因素。将这些摘要嵌入后，预测模型可以同时利用细粒度时间模式和聚合后的日度上下文。

该流程包含三个阶段。

1. **小时级摘要。** 原始文本被划分为固定时间间隔片段，通常每段一小时，以便每个片段都能被预训练 LLM 处理。模型独立压缩每个片段，并保留关键细节。得到的小时摘要按日拼接，保持时间连贯性并显著降低总体序列长度。

2. **日级摘要。** 拼接后的小时摘要再次输入 LLM，生成日度摘要。定制提示引导模型只抽取最显著信息，得到更简洁的表示，并省略冗余或不关键内容。该额外压缩进一步缩短下游任务所需文本。

3. **嵌入抽取。** 从日度摘要中提取 embedding 向量，生成紧凑表示，捕捉语义与上下文细微差异。这些 embedding 作为后续趋势预测模型的输入特征，既反映小时级时间依赖，也包含聚合后的日度概览。

### 3.3 嵌入与对齐模块

**文本嵌入与维度对齐。** 原始文本输入经分层摘要模块处理后，生成 embedding \(X_e \in \mathbb{R}^{B \times L \times d}\)，其中 \(B\) 表示批量大小，\(L\) 表示摘要后的序列长度，\(d\) 表示 embedding 维度。该步骤在保留语义内容的同时降低文本序列长度，从而减少内存占用和计算成本。小时摘要被整合为日度聚合，以便与价格数据的时间粒度同步。受跨模态表征学习和子空间对齐理论启发，本文将文本和数值信号嵌入共同潜在空间，使二者的几何关系可以直接比较。子空间对齐认为，将异构特征投影到共享子空间可以最小化分布差异，并促进有意义的相似度度量。因此，本文使用可学习线性映射并接 dropout 正则化，将 embedding 维度从 \(d\) 调整为价格特征维度 \(d_p\):

\[
X_t = Dropout(Linear(X_e)), \quad X_t \in \mathbb{R}^{B \times L \times d_p}.
\]

其中，`Linear` 表示线性层，`Dropout` 在训练期间随机置零部分单元，以帮助防止过拟合。

**特征对齐。** 为高效整合文本信息与价格特征，本文使用交叉注意力机制对齐文本 embedding 和价格特征。给定文本 embedding \(X_t\) 和价格特征 \(X_p \in \mathbb{R}^{B \times L \times d_p}\)，交叉注意力机制可以比较并整合这两种来源的信息，生成同时捕捉文本内容和价格走势的融合特征。

查询 \(Q\)、键 \(K\)、值 \(V\) 分别为文本和价格特征计算。价格特征 \(X_p\) 通过权重矩阵 \(W_q\) 投影为查询 \(Q\)，文本 embedding \(X_t\) 通过权重矩阵 \(W_k\) 和 \(W_v\) 投影为键 \(K\) 和值 \(V\)。随后计算查询与键的点积以评估文本与价格之间的关系，生成注意力分布，量化每个文本片段对价格预测的影响。之后使用 softmax 归一化注意力分布，得到加权输出特征 \(X_{tp}\)，使最终特征同时反映市场价格波动和文本中的潜在信息。

\[
Q = X_p W_q,\quad K = X_t W_k,\quad V = X_t W_v,
\]

其中 \(W_q, W_k, W_v \in \mathbb{R}^{d_p \times d_k}\)，且 \(d_k = d_p\)。注意力权重计算为:

\[
X_{tp} = softmax\left(\frac{QK^T}{\sqrt{d_k}}\right)V.
\]

这种交叉注意力对齐方法将价格和文本数据整合到共享表征空间，增强模型理解并预测市场波动的能力，尤其适用于建模股票市场波动与新闻事件之间的关系。

**补丁划分与位置投影。** 长序列 \(X_{tp}\) 和 \(X_p\) 被切分为 \(N\) 个长度为 \(P\)、步幅为 \(S\) 的重叠补丁:

\[
N = \left\lfloor \frac{L-P}{S} \right\rfloor + 2,\quad
X_{tp}^{pa}, X_p^{pa} \in \mathbb{R}^{B \times d_p \times N \times P}.
\]

这一补丁策略受到多分辨率信号处理理论以及计算机视觉、语音领域实证结果的启发。局部上下文窗口可以为长序列建模提供有效归纳偏置。具体而言，文本和价格流都被划分为长度为 \(P\) 的窗口，相邻窗口按步幅 \(S < P\) 重叠。从信息论角度看，每个窗口都是局部感受野，使编码器能够捕捉高频细节，例如分钟级情绪变化或微观价格跳跃，而不会被全局上下文淹没。重叠设计缓解边界问题: 横跨两个相邻窗口的事件至少会在一个窗口中完整出现，从而保持片段间连续性。

计算上，补丁化将长度为 \(L\) 的序列的二次自注意力成本 \(O(L^2)\)，转换为 \(N = \lfloor (L-P)/S \rfloor + 2\) 个局部注意力之和，复杂度为 \(O(NP^2)\)。当 \(P \ll L\) 时，这可以将浮点运算量和内存使用大致降低一个数量级，使分钟级盘中数据也能在普通 GPU 上进行小批量训练。由于每个补丁在全局融合阶段前独立处理，所有窗口投影和位置编码都可以在现代加速器上并行执行。

随后，本文对两种模态以相同方式施加位置 embedding 和可学习线性投影，以保持特征变换的一致性。这保证了文本与价格信息在后续阶段中被同等重视。线性投影将补丁表示转换到共享 embedding 空间，位置 embedding 编码每个补丁的相对位置，保留输入数据的顺序结构:

\[
\tilde{X} = X^{pa}W_{proj} + W_{pos},\quad
W_{proj} \in \mathbb{R}^{P \times D},\quad
W_{pos} \in \mathbb{R}^{B \times d_p \times N \times D}.
\]

其中 \(D\) 表示 embedding 维度，\(W_{proj}\) 和 \(W_{pos}\) 为可学习参数，用于优化补丁和位置信息的表征能力。通过这种基于补丁的方法，模型在计算效率与关键语义、时间依赖保留之间取得平衡。

**自注意力增强。** 补丁划分后，重塑后的补丁进一步通过自注意力精炼，以突出最关键特征。自注意力可以捕捉每个补丁内部的依赖关系，使模型关注数据中最相关的部分，而不受其在序列中位置的限制。该机制使模型可以动态调整不同部分的权重，确保关键语义和时间关系得到强调。

自注意力首先从重塑后的补丁 \(\hat{X}\) 中计算查询、键和值矩阵。这里将价格特征维度 \(d_p\) 展平到批量轴，得到标准三维输入张量，即 batch、sequence、channel 格式，且不损失信息:

\[
Q = \hat{X}W_q,\quad K = \hat{X}W_k,\quad V = \hat{X}W_v,\quad
\hat{X} \in \mathbb{R}^{Bd_p \times N \times D}.
\]

随后，查询和键矩阵之间的点积确定注意力得分，再经 softmax 归一化。输出精炼特征表示 \(X_h\)，突出补丁内部关键特征:

\[
X_h = softmax\left(\frac{QK^T}{\sqrt{d_k}}\right)V,\quad
X_h \in \mathbb{R}^{Bd_p \times N \times d_v}.
\]

自注意力使模型能够捕捉补丁内的长程依赖和交互，包括原始序列中距离较远元素之间的关系。结合补丁划分后，自注意力帮助模型同时学习局部和全局依赖，从而适应趋势预测任务中文本和价格数据的复杂性。

### 3.4 协同注意力融合

早期融合拼接会忽略模态间结构，而单向交叉注意力会在模态之间强制固定层级。受双向视觉-语言架构和双编码器对齐理论启发，本文引入双向协同注意力块。在该设计中，文本关注价格，使新闻能够突出价格轨迹中与市场相关的区域；价格反过来关注文本，使价格走势能够为标题解释提供上下文。两个互惠流生成互补特征图，再经拼接和线性投影，形成统一的上下文感知 embedding。

与早期融合相比，该模块保留模态特定结构；与单向交叉注意力相比，它可以捕捉金融决策中固有的反馈回路。

设 \(X_t^h, X_p^h \in \mathbb{R}^{Bd_p \times N \times d_v}\) 为补丁级文本和价格张量，其中 \(N\) 是补丁数，\(d_v\) 是隐藏宽度。\(X_t^h\) 和 \(X_p^h\) 分别表示经自注意力增强后的文本和价格 embedding。使用 \(h\) 个注意力头，每个头宽度为 \(d_h = d_v/h\)。

**流 1: text -> price。** 第一层中，文本 embedding 作为查询，价格 embedding 作为键和值。该设计使文本数据作为主要语义信息源，能够关注包含时间和市场特征的价格数据。对第 \(i\) 个注意力头:

\[
Q^{(i)} = X_t^h W_{q1}^{(i)},\quad
K^{(i)} = X_p^h W_{k1}^{(i)},\quad
V^{(i)} = X_p^h W_{v1}^{(i)}.
\]

注意力输出为:

\[
head_1^{(i)} = softmax\left(\frac{Q^{(i)}K^{(i)T}}{\sqrt{d_h}}\right)V^{(i)},
\]

\[
O_1 = Concat(head_1^{(1)}, \ldots, head_1^{(h)})W_o.
\]

该机制使模型在处理文本数据时选择性关注重要的价格相关特征，增强其解释两类数据交互的能力。

**流 2: price -> text。** 第二个协同注意力层中，查询、键和值角色反转。价格 embedding 作为查询，文本 embedding 作为键和值。该方法使价格数据能够关注文本数据，从而捕捉影响价格动态的重要语义特征:

\[
Q'^{(i)} = X_p^h W_{q2}^{(i)},\quad
K'^{(i)} = X_t^h W_{k2}^{(i)},\quad
V'^{(i)} = X_t^h W_{v2}^{(i)}.
\]

对应注意力输出为:

\[
head_2^{(i)} = softmax\left(\frac{Q'^{(i)}K'^{(i)T}}{\sqrt{d_h}}\right)V'^{(i)},
\]

\[
O_2 = Concat(head_2^{(1)}, \ldots, head_2^{(h)})W'_o.
\]

该层使模型能够突出可能影响价格走势的相关文本信息，并进一步精炼两种模态之间的交互。

两个协同注意力层的输出沿最后一维拼接，以结合来自两个方向的精炼特征表示。随后施加线性变换，得到最终联合表示:

\[
\hat{O} = Linear(Concat(O_1, O_2)),\quad
\hat{O} \in \mathbb{R}^{Bd_p \times N \times d_v}.
\]

为提升训练稳定性并防止过拟合，线性变换输出加入残差连接并接层归一化。该过程确保学习到的表示同时保留原始特征和增强后的协同注意力信息:

\[
Z_1 = LayerNorm(\hat{O} + X_p^h),\quad
Z_2 = FFN(Z_1),\quad
Z = LayerNorm(Z_1 + Z_2).
\]

其中 \(Z \in \mathbb{R}^{Bd_p \times N \times d_v}\) 是最终联合特征表示。

**计算特征与通用性。** 当有 \(h\) 个注意力头且每头宽度为 \(d_h = d_v/h\) 时，每个协同注意力流在每个 batch 上执行的操作量为 \(hO(N^2d_h) = O(N^2d_v)\)，只在补丁数量 \(N\) 上呈二次复杂度，而 \(N \ll L\)。由于所有注意力头和两个流都可并行运行，该融合块在现代 GPU 上易于并行，即使面对分钟级盘中序列也保持可处理性。

该架构本身与模态无关: 价格通道可以替换为任意数值时间序列，例如电子病历中的生命体征、与警报消息配对的交通流量，或与天气公告配对的能源需求，而无需改变模型结构。因此，双向协同注意力模板为跨模态时间建模提供了一种可复用蓝图。

总之，本文机制在保留模态特定结构的同时捕捉丰富的模态间依赖，生成语义增强的联合表示，从而有利于股票趋势分类等下游任务。

### 3.5 分类模块

最终联合特征张量 \(Z\) 首先通过拼接模态维和补丁维被重塑为二维矩阵。展平操作得到:

\[
z_f = flatten(Z),\quad z_f \in \mathbb{R}^{Bd_p \times Nd_v}.
\]

该向量经过全连接层和 sigmoid 激活函数，得到预测趋势概率:

\[
\hat{y} = \sigma(z_fW_c + b),\quad \hat{y} \in \mathbb{R}^{Bd_p \times l}.
\]

其中 \(W_c \in \mathbb{R}^{Nd_v \times l}\)，\(b \in \mathbb{R}^l\)，且 \(\sigma(x) = 1/(1+e^{-x})\)。

模型参数 \(\{W_c, b\}\) 通过最小化训练集上的二元交叉熵损失进行优化:

\[
\mathcal{L}_{BCE} = -[y\log\hat{y} + (1-y)\log(1-\hat{y})].
\]

其中 \(y \in \{0,1\}^{(Bd_p)\times l}\) 是真实标签。该配置确保输出 \(\hat{y}\) 表示价格上涨的概率。

### 4.2 问题定义与实验设置

本文将股票走势预测定义为二元次日趋势预测问题: 给定截至日期 \(\tau\) 的价格序列和同期文本，预测 \(\tau+1\) 日的收盘价是否高于 \(\tau\) 日。设 \(x_\tau\) 表示 \(\tau\) 日收盘价，目标变量 \(y_{\tau+1}\) 定义为:

\[
y_{\tau+1} =
\begin{cases}
1, & \text{若 } x_{\tau+1} > x_\tau \text{，即上涨};\\
0, & \text{若 } x_{\tau+1} \le x_\tau \text{，即下跌或不变}.
\end{cases}
\]

该二元设定与交易决策一致，并被多模态股票预测广泛采用。对日期 \(\tau\) 的每次预测，模型使用两种时间对齐模态: 第一，价格序列，即长度 \(L=30\) 的交易日收盘价窗口；第二，文本序列，即同一个 30 日窗口内的全部金融新闻，经过第 3.2 节的分层摘要模块处理后得到日度 embedding。不同于一些方法使用幅度阈值过滤小波动，本文不设置阈值: 只要 \(x_{\tau+1} > x_\tau\) 就标记为上涨，否则标记为 0。该严格策略允许模型学习所有尺度上的方向信号，包括可能预示更大波动的细微动量。

经验上，日度波动分布较为合理: CMIN-US 中 52.3% 的日期为上涨，平均绝对日变动为 1.87%；CMIN-CN 中 48.6% 的日期为上涨，平均绝对日变动为 2.14%。这说明在不设阈值的情况下，类别比例天然较合理。为避免前视偏差，本文按时间顺序将 2018-01-01 至 2021-12-31 的完整样本划分为训练集、验证集和测试集: 训练集为 2018-01-01 至 2020-06-30，约 630 个交易日，占 62.5%；验证集为 2020-07-01 至 2020-12-31，约 126 个交易日，占 12.5%；测试集为 2021-01-01 至 2021-12-31，约 252 个交易日，占 25%。

对每只股票 \(s\) 和满足条件的每个日期 \(\tau\)，使用长度为 \(L\) 的窗口和次日标签构造样本。CMIN-US 训练样本约为 69,300 个，CMIN-CN 约为 189,000 个，验证集和测试集按比例构建。标签存在轻微但真实的类别不平衡，因此除准确率外，本文还报告 Matthews 相关系数，以便在不重采样或加类别权重的情况下公平评估两类表现。

模型配置方面，本文使用预训练 mT5_multilingual_XLSum 模型。该模型是基于 T5 架构并在 XLSum 语料上训练的多语言摘要模型，适合对复杂文本生成丰富表示。整体架构包含三个模块: 对齐与嵌入、协同注意力融合、分类。序列长度 \(L=30\)，补丁大小为 10，步幅为 5，隐藏维度 \(d_{model}=128\)，前馈维度 \(d_{ff}=256\)。模型使用 GELU 激活和 0.2 dropout。输出层给出二元趋势分类概率。训练初始学习率为 \(1 \times 10^{-4}\)，每 5 个 epoch 应用 \(1 \times 10^{-4}\) 的衰减。

**预处理与数据完整性。** 为保证数据质量和模型可靠性，本文针对金融时间序列中的常见问题设计了多阶段预处理流程。对于假日、停牌或采集错误导致的缺失交易日，若缺口不超过连续 3 天，则以前一日收盘价前向填充；若某只股票在 2018-2021 年间缺失天数超过总交易日的 5%，则排除该股票。该流程从 CMIN-US 移除 2 只股票，从 CMIN-CN 移除 4 只股票，最终分别保留 108 只和 296 只用于评估。

为缓解极端价格波动对归一化统计的扭曲，本文对每只股票独立应用 3-sigma 规则: 使用训练期日对数收益计算 \(\mu_s\) 和 \(\sigma_s\)，将超出 \(\mu_s \pm 3\sigma_s\) 的收益截断到边界。同时，结合同期文本活动进行交叉检查，以保留与真实大幅波动相关的有信息事件。两个数据集中被截断的日收益少于 0.8%。

为减少重复通稿带来的文本冗余，本文计算同一股票同一交易日所有文章之间的两两 Levenshtein 距离，当字符级重叠超过 90% 时只保留最早时间戳版本。这使 CMIN-US 的文章数量减少约 18%，CMIN-CN 减少约 22%，并使建模更集中于独特信息。随后，原始新闻文本经过去除非字母数字字符、合并重复空白、过滤短于 50 字符文章、统一小写等处理，并用预训练 mT5 tokenizer 在 512 token 输入限制内进行分词。所有预处理超参数都在训练集上固定，并原样应用于验证集和测试集，以防信息泄漏。

### 4.3 评价指标

为严格评估预测性能并缓解类别不平衡影响，本文使用两个互补指标: 分类准确率 ACC 和 Matthews 相关系数 MCC。ACC 衡量整体正确率，MCC 即使在类别频率不同时也能提供平衡评价。

\[
ACC = \frac{TP + TN}{TP + TN + FP + FN}
\]

\[
MCC = \frac{TP \times TN - FP \times FN}{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}}.
\]

其中，TP 表示正确预测上涨，TN 表示正确预测下跌，FP 表示趋势预测中的 I 类错误，FN 表示 II 类错误。

### 4.4 基线方法

本文将所提出模型与七种先进股票趋势预测方法比较:

- **ALSTM:** 使用双层注意力在历史时间步上选择性加权时间特征的层次注意力循环网络。
- **StockNet:** 整合递归连续潜变量的变分循环框架，通过变分推断处理时间序列建模中的后验估计问题。
- **Adv-LSTM:** ALSTM 的对抗训练变体，用于增强分布转移下的鲁棒性和泛化能力。
- **DTML:** 显式引入股票间相关矩阵的注意力驱动架构，用于精炼特征表示并增强方向预测。
- **CMIN:** 端到端多模态网络，将金融文本 embedding 与因果增强的股票相关图融合，实现文本和数值模态联合建模。
- **LLMFactor:** 基于提示的方法，利用 LLM 生成序列引导提示，识别并加权影响股票走势的关键文本因素。
- **CausalStock:** 新闻驱动框架，推断股票之间具有滞后的因果关系，并使用基于 LLM 的去噪器增强多股票走势预测。

配对 t 检验显示性能提升在 \(p < 0.01\) 下具有统计显著性，说明结果并非随机初始化造成。模型在不同监管制度下的两个市场都取得一致收益，也说明其具备一定鲁棒性和泛化能力。

### 4.6.1 LLM 性能比较

为评估模型稳定性、可部署性以及 LLM 选择对预测性能的影响，本文进行了三项互补评估。第一，通过模拟交易评估风险调整收益和组合层面指标。第二，测量推理延迟和计算可扩展性，以考察实时部署可行性。第三，系统比较通用模型、领域适配模型和摘要预训练模型。表 7 报告了 10 个随机种子独立运行的均值和标准差。所有模型使用相同数据划分，并在统一回测协议下评估: 初始资金 100,000 美元，双边交易成本 0.1%，入场置信阈值 0.6，最短持有期 3 天。

**风险调整表现和经济意义。** 分类准确率有参考价值，但实际交易系统还需要在波动、尾部风险和回撤约束下获得稳健的风险调整收益。因此，本文实现模拟交易引擎: 当预测上涨概率超过 0.6 时做多，否则持有现金；交易成本为 0.1%，最短持有期 3 天，并采用与置信度成比例的仓位规模。表 7 显示，基于 mT5-XLSum 的分层摘要框架相对于 BERT-base、FinBERT 和 XLM-RoBERTa 获得最高 Sharpe 比率和更好的年化收益。其收益来自两阶段分层摘要在过滤微观噪声的同时保留事件结构，补丁时间编码捕捉局部动态和多日趋势，双向协同注意力显式建模文本-价格交互并发现高置信度非对称机会。年化收益验证了经济价值，而下行风险也控制得更好，Calmar 比率更高。扣除成本后胜率达到 56.7% ± 1.2%，高于 50% 的正期望阈值。

**推理效率、可扩展性与实时可行性。** 实时交易需要毫秒级延迟。在单张 NVIDIA RTX 5080 上对 1,000 次前向传播取平均，mT5-XLSum 每个 batch 的推理时间为 15.79 ± 0.48 ms，约为每个样本 1.97 ms，处于盘中策略常见的 10-100 ms 预算内。尽管参数规模较大，由于补丁编码降低了注意力复杂度，协同注意力只作用于补丁级 embedding，其延迟仍具有竞争力。

**LLM 架构对分层摘要的影响。** 用于分层摘要的预训练语言模型会显著影响语义抽取和效率。表 7 显示，mT5-XLSum 在分类指标和组合指标上都持续领先，说明面向摘要任务的预训练比领域词汇或多语言覆盖本身更关键。编码器-解码器的去噪目标鼓励模型提炼显著命题并抑制冗余，这与小时到日的摘要流程高度一致；而 BERT/FinBERT 等 masked-LM 目标更强调局部 token 重建，在文本已经压缩后提升较小。XLM-RoBERTa 延迟最低，但风险调整收益最弱；其多语言预训练能提供分类特征，却不总能在扣除成本和持仓约束后稳定捕捉与交易相关的情绪和事件显著性。

### 4.7 极端价格波动案例研究

为突出分层摘要模块的可解释性和有效性，本文分析了 CMIN-US 中 AAPL 的两个极端价格波动案例。通过对比分层摘要、原始 embedding 和单阶段摘要，作者展示了分层设计如何引导模型关注最有信息量的线索，并提升预测性能。

**案例 A: 2018 年 11 月 1 日财报超预期，上涨 7.3%。** 当日 AAPL 季度收益显著超过分析师预期，推动股价上涨 7.3%。当模型只依赖原始 embedding 或单阶段摘要时，无法捕捉这次超预期的持续影响: 注意力分散在通用词语上，并低估了“利润率扩张”等关键短语，从而削弱信号。使用分层摘要时，小时片段先被抽取，再在日内聚合，使模型聚焦于“EPS 上调”和“提高指引”等核心段落。在 PCA 散点图中，这表现为明显的“深入 + 看涨”聚类。因此，一日预测准确率提升约 3.3 个百分点，MCC 提升约 0.02，与表 5 中的整体增益一致。

**案例 B: 2018 年 12 月 24 日监管罚款，下跌 6.6%。** 当日有新闻称 AAPL 面临重大监管罚款，引发 6.6% 下跌。原始 embedding 或单阶段摘要通常只捕捉“罚款”和“监管”等高频词，却忽略处罚规模和后续影响，因此对看跌信号反应不足。分层摘要在第一阶段保留多篇详细报道，包括罚款金额和合规承诺，在第二阶段将其压缩成聚焦的负面深度摘要。PCA 散点图显示出清晰的“深入 + 看跌”聚类，使模型能够预判急剧下跌。在该案例中，分层摘要使 MCC 提升约 0.02，体现了该方法带来的鲁棒性和稳定性增益。

### 4.8 超参数研究

本文对协同注意力融合模块的两个超参数进行网格搜索: 融合层数 \(M\) 和每层注意力头数 \(H\)。图 4 报告了两个基准数据集上全部 16 个 \((M,H)\) 配置的 ACC 和 MCC。

**CMIN-US 结果。** 当 \(M=2, H=16\) 时，准确率最高，为 67.01%。当 \(M=4, H=8\) 时，MCC 最高，为 0.350，此时 ACC 为 63.12%。

**CMIN-CN 结果。** 当 \(M=4, H=4\) 时，准确率最高，为 70.24%。当 \(M=2, H=32\) 时，MCC 最高，为 0.299，此时 ACC 为 68.70%。

基于这些发现，本文在 CMIN-US 上采用 \(M=2, H=16\) 以优化准确率，在 CMIN-CN 上采用 \(M=4, H=4\) 以优化准确率。如果更重视 MCC，也可选择其他设置。

## 5. 讨论

本文提出了一个统一框架，通过分层语言建模、基于补丁的时间编码和协同注意力融合金融新闻与历史价格序列。在 CMIN-US 基准上，模型达到 67.01% 准确率和 0.346 MCC；在 CMIN-CN 上达到 70.24% 准确率和 0.293 MCC，优于单模态基线和更简单的融合方法。

详细分析得到四个主要见解。第一，将文本特征与价格数据结合，可以相对于纯价格模型带来 5-9 个百分点的准确率提升，以及 0.015-0.217 的 MCC 提升，说明新闻文章中的语义信息可以补充价格波动。第二，多阶段 LLM 摘要策略优于直接 embedding 和单阶段方法，最高带来 3.3 个百分点准确率提升和 0.022 MCC 提升，凸显了输入长度限制下分层语义精炼的重要性。第三，基于补丁的编码在降低注意力复杂度的同时保留局部和全局时间结构，使长价格序列能够被高效建模。第四，协同注意力实现了最有效的模态融合，相比传统交叉注意力，最高带来 1.35 个百分点准确率提升和 0.045 MCC 提升，说明文本与价格表示之间的动态细粒度对齐具有价值。这些结果推进了对联合表征学习的理解，展示了分层语义蒸馏、高效时间编码和动态融合如何在一个架构内结合。

本文仍存在若干局限。第一，研究依赖尚未在金融文本上微调的通用 LLM，这可能限制其捕捉专业市场术语的能力。第二，固定补丁大小和步幅可能难以泛化到具有异质波动特征的不同资产。第三，评估仅限于 CMIN-US 和 CMIN-CN 基准，模型对其他市场或不同时间跨度的泛化能力仍有待研究。尽管如此，实验表明，分层摘要、补丁编码和协同注意力融合共同提升了多模态股票趋势预测性能。

未来研究应关注以下方向: 在行业特定语料上微调语言模型，以增强其对专业术语的理解；设计能够适应资产层面波动率的自适应补丁方案；整合社交媒体情绪、宏观经济指标等额外数据源以提升鲁棒性；将该框架部署到生产级实时推理流水线中，以严格评估延迟和可扩展性。

## 6. 结论

本文提出了一种由大语言模型驱动的多模态股票趋势预测框架，为两个核心挑战提供统一解决方案: 从冗长金融文本中抽取显著信号，以及建模文本语义与价格动态之间的双向依赖。该框架使用分层摘要提炼新闻语义，使用基于补丁的时间模块稳健编码价格和文本的序列结构，并通过文本-价格协同注意力融合两种模态，形成更丰富、噪声更低的联合表示。跨市场基准实验显示，该方法在方向准确率、风险调整收益和推理效率方面都相对于强基线获得一致提升。消融实验进一步表明，分层摘要、基于补丁的时间建模和协同注意力都提供了实质增益，三者结合时效果最佳。总体而言，结果证明，将任务对齐的语义蒸馏、高效时间建模和显式跨模态交互结合起来，可以显著提升多模态金融预测的准确性和实用性。
