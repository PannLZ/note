## 给你的最短路径

1. 先读 `FinBen`、`FinMME`、`CausalStock` 或 `From News to Forecast`，建立任务地图。
2. 再读 `FinCon`、`A Multimodal Foundation Agent`、`DeepFund`，理解 Agent 的时间安全和决策闭环。
3. 最后读 `PHANTOM`、`FinGEAR`、`Reasoning on Time-Series`，把可信 RAG 和 LLM+时序推理串起来。



如果你想看 **LLM Agent × 金融**，我建议优先读这几篇，按阅读价值排序：

我建议你的阅读顺序是：

1. **先读综述**：Large Language Model Agents in Finance
2. **再读自动化投研**：R&D-Agent-Quant、Automate Strategy Finding
3. **再读交易系统**：Trade in Minutes、FinCon
4. **最后看平台/多模态扩展**：PortfolioPilot、A Multimodal Foundation Agent

如果只选三篇，读：**Large Language Model Agents in Finance + R&D-Agent-Quant + Automate Strategy Finding with LLM in Quant Investment**。
