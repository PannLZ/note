## 关键观察

- 宽口径中，图学习/KG/欺诈/异常/风控最多（22 篇），其次是股票/市场预测/时序/因果（18 篇）、Agent/策略自动化（14 篇）、RAG/检索/长上下文/事实核查（12 篇）。
- 如果把 Agent、RAG、金融 LLM benchmark、域适配/Embedding、数值推理合并为“LLM 相关生态”，共有 **53 / 123** 篇，约 **43.1%**。
- 多模态在总量上不是最大类（8 篇），但 2025-2026 的新增 benchmark 密度高，选题空间偏“评测定义 + 文档/图表推理 + verifier”。
- 时序预测不是单纯涨跌预测最有优势；更值得读和做的是 LLM 事件因子、因果结构、多模态事件驱动预测、金融时序预训练。
- Agent 方向增长快，但真正的难点不是搭 agent，而是时间安全、无泄漏回测、可审计决策链和工具调用闭环。

## 建议阅读顺序

1. 先读 FinBen / FinMME / CausalStock，建立金融 LLM、多模态、时序预测三条线的任务定义。
2. 再读 FinCon / A Multimodal Foundation Agent / DeepFund，把 agent 的闭环、工具、多模态和时间安全补上。
3. 最后读 PHANTOM / FinGEAR / Reasoning on Time-Series，把可信 RAG、证据校验和 LLM+时序推理串起来。
