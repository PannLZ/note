## 2. 按研究主题推荐

### 2.1 主题 A：排序推荐式股票选择

#### 1. Relational Stock Selection via Probabilistic State Space Learning

- 作者：Qiang Gao, Zhengxiang Liu, Li Huang, Kunpeng Zhang, Jun Wang, Guisong Liu
- 年份：2025
- 期刊/分区：IEEE Transactions on Knowledge and Data Engineering；中科院一区；CCF A 期刊
- 链接：[DOI 10.1109/TKDE.2024.3509267](https://doi.org/10.1109/TKDE.2024.3509267)
- 摘要要点：将股票选择建模为股票对之间的相对收益排序问题，用概率状态空间学习动态关系，再做 stock ranking。
- 与金融科技的关联性：直接面向股票选择和投资组合构建，比单纯涨跌分类更贴近金融收益目标。
- 与推荐系统前沿的关联：可对接 BPR、pairwise ranking、listwise ranking、动态负采样和 Top-K 推荐评价。
- 推荐程度：★★★★★
- 建议读法：优先读问题定义、loss 设计和实验指标，重点看它如何把“预测”改写成“排序”。

### 2.2 主题 B：图推荐、动态图与股票关系建模

#### 2. MagicNet: Memory-Aware Graph Interactive Causal Network for Multivariate Stock Price Movement Prediction

- 作者：Di Luo, Shuqi Li, Weiheng Liao, Rui Yan
- 年份：2025
- 期刊/分区：IEEE TKDE；中科院一区；CCF A 期刊
- 链接：[DOI 10.1109/TKDE.2025.3527480](https://doi.org/10.1109/TKDE.2025.3527480)
- 摘要要点：为股票设置文本记忆槽，结合因果图交互建模股票间非对称影响。
- 与金融科技的关联性：适合价格序列与金融文本共同驱动的股票运动预测。
- 与推荐系统前沿的关联：对应 memory-augmented sequential recommendation、图交互推荐、因果推荐。
- 推荐程度：★★★★★
- 建议读法：重点看“记忆槽”怎么设计，它很适合迁移到 SASRec / SR-GNN 的金融版本。

#### 3. Financial Time Series Prediction With Multi-Granularity Graph Augmented Learning

- 作者：Peng Zhu, Yuante Li, Qinyuan Liu, Dawei Cheng, Changjun Jiang
- 年份：2025
- 期刊/分区：IEEE TKDE；中科院一区；CCF A 期刊
- 链接：[DOI 10.1109/TKDE.2025.3607005](https://doi.org/10.1109/TKDE.2025.3607005)
- 摘要要点：在周、日、分钟等多时间粒度上构建金融关系图，并用图增强模块融合不同频率信号。
- 与金融科技的关联性：适合多频交易数据、基本面数据和股票关系联合建模。
- 与推荐系统前沿的关联：对应 multi-scale user behavior modeling、长短期兴趣融合、多粒度图推荐。
- 推荐程度：★★★★★
- 建议读法：优先看多粒度图如何构建，以及它相对于单一时间粒度模型的增益。

#### 4. TGNS: A Transformer-Based Graph Neural Network for Stock Trend Forecasting

- 作者：Haichao Du, Li Lv, Hongliang Wang, An Guo
- 年份：2025
- 期刊/分区：Information Sciences；中科院一区
- 链接：[DOI 10.1016/j.ins.2025.122555](https://doi.org/10.1016/j.ins.2025.122555)
- 摘要要点：融合 Transformer 的全局时序建模能力和 GNN 的股票关系建模能力，用于趋势预测。
- 与金融科技的关联性：处理股票趋势预测中的时序依赖和跨股票关系。
- 与推荐系统前沿的关联：适合连接序列推荐 Transformer 与图推荐 GNN。
- 推荐程度：★★★★☆
- 建议读法：把它当作“Transformer + GNN 金融基线”，与 SASRec + LightGCN 的组合做类比。

#### 5. A Dynamic-Causal Lens of Stock Interactions: Graph Modeling From Symbolic Movement Patterns

- 作者：Haotian Liu, Bowen Hu, Yadong Zhou, Yuxun Zhou
- 年份：2026
- 期刊/分区：IEEE TKDE；中科院一区；CCF A 期刊
- 链接：[DOI 10.1109/TKDE.2025.3638410](https://doi.org/10.1109/TKDE.2025.3638410)
- 摘要要点：从符号化价格运动模式出发，建模股票交互中的动态因果结构。
- 与金融科技的关联性：适合解释股票关系为什么随时间变化，尤其适合市场 regime 切换场景。
- 与推荐系统前沿的关联：对应动态图推荐、因果图推荐、可解释推荐。
- 推荐程度：★★★★☆
- 建议读法：重点看“图结构如何从模式中生成”，可作为 Agent 构图方向的理论支撑。

#### 6. Understanding Interactive Stock Dynamics via Sensitivity-Aware Dependency Learning

- 作者：Li Huang, Yanzhe Xie, Zizheng Wang, Qiang Gao, Kunpeng Zhang, Philip S. Yu
- 年份：2026
- 期刊/分区：IEEE TKDE；中科院一区；CCF A 期刊
- 链接：[DOI 10.1109/TKDE.2026.3675433](https://doi.org/10.1109/TKDE.2026.3675433)
- 摘要要点：通过短期协整检测、长期共动追踪和敏感性依赖学习建模股票间互动。
- 与金融科技的关联性：用于捕捉跨股票影响、行业共动和长期结构依赖。
- 与推荐系统前沿的关联：对应协同过滤中的 cross-item dependency learning，可迁移到 LightGCN / GraphSAGE / HGT。
- 推荐程度：★★★★★
- 建议读法：重点看短期动态和长期结构如何结合，这对推荐系统迁移很有启发。

#### 7. Unleashing Expert Opinion From Social Media for Stock Prediction

- 作者：Wanyun Zhou, Saizhuo Wang, Xiang Li, Yiyan Qi, Jian Guo, Xiaowen Chu
- 年份：2026
- 期刊/分区：IEEE TKDE；中科院一区；CCF A 期刊
- 链接：[DOI 10.1109/TKDE.2025.3626439](https://doi.org/10.1109/TKDE.2025.3626439)
- 摘要要点：从社交媒体中识别专家和反向专家，再用 DualGAT 将专家信号传播到相关股票。
- 与金融科技的关联性：利用 StockTwits 等社交平台的投资者观点改进股票预测。
- 与推荐系统前沿的关联：对应社交推荐、专家发现、influencer detection、可信用户建模。
- 推荐程度：★★★★☆
- 建议读法：如果你想做“社交信号 + 推荐式选股”，这篇优先级很高。

### 2.3 主题 C：Transformer、Informer 与金融序列建模

#### 8. Long Short-Term Financial Time Series Forecasting Based on Residual Multiscale TCN Sparse Expert Network and Informer

- 作者：Wuzhida Bao, Yuting Cao, Yin Yang, Shiping Wen

- 期刊/分区：IEEE Transactions on Neural Networks and Learning Systems；中科院一区
- 链接：[DOI 10.1109/TNNLS.2025.3584369](https://doi.org/10.1109/TNNLS.2025.3584369)
- 摘要要点：结合残差多尺度 TCN、稀疏专家网络和 Informer，用于长短期金融时序预测。

- 与推荐系统前沿的关联：对应多尺度序列建模、稀疏专家路由、长序列注意力。
- 推荐程度：★★★★☆
- 建议读法：作为 baseline 读，不一定作为主创新来源。

### 2.4 主题 D：超图与对比学习

#### 9. FactorGCL: A Hypergraph-Based Factor Model with Temporal Residual Contrastive Learning for Stock Returns Prediction

- 作者：Yitong Duan, Weiran Wang, Jian Li
- 年份：2025
- 会议/等级：AAAI 2025；CCF A
- 链接：[DOI 10.1609/aaai.v39i1.31993](https://doi.org/10.1609/aaai.v39i1.31993)
- 摘要要点：用超图建模股票收益与因子之间的高阶关系，并通过 temporal residual contrastive learning 学习隐藏因子。

## 4. 最建议形成的 3 个课题方向

### 方向一：LLM 增强的序列推荐式股票选择

- 核心想法：把股票历史状态序列建模成 item sequence，用 SASRec/BERT4Rec/SR-GNN 做 Top-K 股票选择，再让 LLM 提供事件 token、主题 token、风险 token。
- 关联论文：Relational Stock Selection、TGNS、Integrative LLM + Patch Transformer、Financial News Sentiment。
- 推荐系统前沿关联：LLM4Rec、序列推荐、BPR/listwise ranking、多模态推荐。
- 为什么值得做：比“LLM 直接预测股价”更贴合你们实验室积累，也更容易讲清楚迁移价值。

### 方向二：Agent 驱动的动态股票关系图学习

- 核心想法：让不同 LLM Agent 从新闻、财报、行业、宏观、技术面视角生成候选股票关系图，再用 LightGCN/HGT/GNN 做排序预测。
- 关联论文：MagicNet、Multi-Granularity Graph、Dynamic-Causal Lens、Sensitivity-Aware Dependency Learning。
- 推荐系统前沿关联：Agent4Rec、图推荐、动态图推荐、因果推荐。
- 为什么值得做：现有金融图大多依赖统计相关或先验关系，Agent 可补充解释型、事件型边。

### 方向三：金融时序-文本双视图对比学习

- 核心想法：价格序列 encoder 学数值视图，LLM 学新闻/公告语义视图，通过对比学习对齐两种表示，再用于股票排序。
- 关联论文：FactorGCL、PA-TMM、Integrative LLM + Patch Transformer。
- 推荐系统前沿关联：CL4SRec、DuoRec、SimGCL、SGL、多视图推荐。
- 为什么值得做：对比学习是推荐系统强项，金融场景已有 FactorGCL 证明可行，但 LLM 语义对齐还不充分。

## 5. 我最推荐的开题路径

如果只选一个方向，我建议优先选：

**LLM 增强的序列推荐式股票选择**

建议技术路线：

1. 用 SASRec / BERT4Rec / SR-GNN 跑通只含价格和技术指标的股票序列推荐 baseline。
2. 用 LLM 从新闻、公告、宏观事件中抽取结构化事件 token。
3. 把事件 token 作为 side sequence、attention bias 或图边权注入推荐模型。
4. 用 BPR/listwise ranking 代替单纯 CE/MSE。
5. 评价 RankIC、NDCG@K、Top-K 组合收益、Sharpe、最大回撤、换手率和交易成本后收益。

这个方向的论文故事可以写成：

> 现有 LLM 金融预测多数把 LLM 当作情感特征提取器，而推荐系统擅长序列建模与 Top-K 排序。本文将金融预测重构为序列推荐问题，并通过 LLM 事件语义增强推荐模型的时序注意力与排序目标。

## 6. 不建议作为主线的方向

### 6.1 纯 LLM 股票预测

不建议把课题定成“LLM 预测股票涨跌”。原因：

- 竞争非常拥挤；
- 和推荐系统实验室积累关系弱；
- 很容易停留在 prompt / sentiment engineering；
- 金融收益目标和分类准确率容易不一致。

### 6.2 只做普通时序预测模型替换

例如“把 Informer 换成 Mamba”或“把 LSTM 换成 Transformer”也不够推荐。原因：

- 金融时序模型更新很快；
- 纯时序预测不突出推荐系统迁移；
- 期刊审稿中容易被认为只是模型堆叠。

更好的方式是：把时序模型放进推荐排序框架中，并引入 LLM/Agent 做知识增强。
