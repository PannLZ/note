## 0. 核验口径与结论先行

### 0.1 纳入标准

### 0.2 总体判断

推荐系统前沿技术已经较深地进入金融场景，但进入方式有明显层次：

1. **最成熟的交叉点是“排序推荐式选股”**：股票预测不再只做涨跌分类或收益回归，而是建模相对收益、Top-K 资产排序、买赢家卖输家组合。
2. **GNN / 异构图 / 动态关系图是金融场景吸收推荐技术最充分的方向**：股票关系、行业关系、供应链、共同概念、社交专家信号都可转为图上的协同信号传播。
3. **Transformer / 时序注意力已进入金融预测，但与推荐系统中的 SASRec / BERT4Rec / session-based recommendation 尚未充分打通**。
4. **LLM 当前多作为文本特征提取器或 Agent 外围模块**，与推荐系统核心模块的紧耦合仍少，正是可做课题的空间。
5. **最适合你的方向不是“纯 LLM 预测股价”**，而是“以推荐系统为主体，用 LLM/Agent 做知识注入、图构建、记忆与反思增强”。

## 2. 主题一：哪些推荐系统前沿技术已被引入金融场景

### 2.1 排序推荐与投资组合目标

#### 1. Temporal Relational Ranking for Stock Prediction

- 作者：Fuli Feng, Xiangnan He, Xiang Wang, Cheng Luo, Yiqun Liu, Tat-Seng Chua
- 年份：2019
- 期刊/分区：ACM Transactions on Information Systems；中科院一区；CCF A 期刊
- 链接：[DOI 10.1145/3309547](https://doi.org/10.1145/3309547)
- 摘要要点：提出 Relational Stock Ranking，将股票预测从分类/回归转为面向投资目标的排序问题；用 Temporal Graph Convolution 同时建模股票关系和时间演化。
- 与金融科技的关联性：直接服务选股和投资组合构建，强调“选出收益最高的股票”比“预测单点价格”更贴近金融目标。
- 推荐系统关联：与 Learning-to-Rank、图推荐、关系建模高度一致，是“推荐系统视角做金融预测”的基础论文。

#### 2. AlphaStock

- 作者：Jingyuan Wang, Yang Zhang, Ke Tang, Junjie Wu, Zhang Xiong
- 年份：2019
- 会议/等级：KDD 2019；CCF A
- 链接：[DOI 10.1145/3292500.3330647](https://doi.org/10.1145/3292500.3330647)
- 摘要要点：提出可解释深度强化注意力网络，用“买赢家、卖输家”的投资策略直接优化组合表现。
- 与金融科技的关联性：强调收益、组合和交易策略，而不只是预测准确率。
- 推荐系统关联：可与推荐中的排序、Top-K、长期收益优化结合；也提示未来 loss 应从 CE/MSE 转向排序收益或风险收益目标。

#### 3. Relational Stock Selection via Probabilistic State Space Learning

- 作者：Qiang Gao, Zhengxiang Liu, Li Huang, Kunpeng Zhang, Jun Wang, Guisong Liu
- 年份：2025
- 期刊/分区：IEEE TKDE；中科院一区；CCF A 期刊
- 链接：[DOI 10.1109/TKDE.2024.3509267](https://doi.org/10.1109/TKDE.2024.3509267)
- 摘要要点：用概率状态空间学习股票间关系，预测股票对之间的相对期望收益，并做股票排序。
- 与金融科技的关联性：面向股票选择和组合构建，是近期一区期刊里最接近“推荐式选股”的工作。
- 推荐系统关联：可自然对接 BPR、pairwise ranking、自适应负采样、Top-K ranking loss。

## 3. 主题二：技术缺口与可研究空白

### 3.1 LLM 与推荐式金融模型仍是松耦合

现有一区期刊中，LLM 多用于新闻情感、文本摘要、事件抽取，随后把分数或 embedding 丢给 LSTM/Transformer/GNN。它还没有充分参与：

- SASRec/BERT4Rec 式序列 attention 的 query/key/value 构造；
- 图推荐中的边权生成、动态图更新、负采样；
- Top-K 股票排序损失或组合收益目标的端到端优化；
- Agent 对模型选择、样本构造、反思反馈的闭环。

你的机会：把 LLM 从“文本特征提取器”提升为“推荐模型结构增强器”。

### 3.2 金融任务的评价目标与机器学习目标仍不一致

很多论文仍报告 accuracy、F1、MSE、MAPE，但真实投资关心：

- RankIC / ICIR；
- Top-K 命中后的组合收益；
- 夏普比率、最大回撤、换手率、交易成本；
- 多市场、跨时间 regime 的稳定性。

推荐系统的 BPR、listwise ranking、counterfactual ranking、risk-aware ranking 可以补这个缺口。

### 3.3 动态股票图构建还缺少 Agent 化解释

TKDE 近期论文已大量做动态股票图、因果图、敏感性依赖图，但图的构建仍主要来自价格统计、行业先验、协整或模型注意力。LLM Agent 可作为“图构建分析师”：

- 从新闻/公告/财报中抽取公司关系；
- 从宏观事件中推断行业共振；
- 从投资者叙事中识别短期主题轮动；
- 用多 Agent 视角生成多张候选图，再由 GNN/LightGCN 学习融合。

### 3.4 推荐系统中的冷启动、长尾与负采样还没有充分迁移

金融场景天然存在：

- 新股/低流动性股票冷启动；
- 小盘股和概念股长尾；
- 熊市/极端事件样本稀缺；
- “负样本”不是不相关资产，而是风险收益劣于候选资产的相对对照。

推荐系统中的长尾推荐、hard negative mining、自适应负采样、对比增强可直接迁移。

### 3.5 Agent 金融框架缺少强时序骨干

TradingAgents、TS-Agent 等方向显示 Agent 在金融中很热，但 Agent 框架往往把时序预测当作一个普通工具，没有充分引入推荐系统中成熟的序列建模结构。你的实验室若有 SASRec/BERT4Rec/SR-GNN 积累，可以把它包装为“时序分析 Agent”或“市场状态检索器”。

## 4. 主题三：推荐课题方向

### 方向一：LLM 增强的序列推荐式股票选择

- 核心问题：把股票历史状态序列建模为 item sequence，把下一期 Top-K 股票选择建模为 sequential recommendation。
- 推荐系统关联：SASRec、BERT4Rec、CL4SRec、DuoRec、BPR/listwise ranking。
- LLM/Agent 角色：从新闻、公告、宏观事件中抽取 event tokens，作为序列 token、side feature 或 attention bias。
- 可复用文献：Temporal Relational Ranking、Relational Stock Selection、ALSP-TF、Financial News Sentiment、Integrative LLM + Patch Transformer。
- 可能创新：从“LLM 情感分数 + 时序模型”升级为“LLM 事件语义直接参与推荐式序列 attention”。
- 风险：金融数据噪声高，需要强基线和稳健评估。
- 推荐程度：最高。最符合实验室推荐系统积累，也满足你对 LLM 的兴趣。

### 方向二：Agent 驱动的动态金融图构建与 LightGCN 选股

- 核心问题：让多个 LLM Agent 从不同投资视角构建股票关系图，再用 GNN/LightGCN 做股票排序。
- 推荐系统关联：LightGCN、HGT、图推荐、动态图推荐、social recommendation。
- LLM/Agent 角色：价值投资 Agent、趋势交易 Agent、新闻事件 Agent、风险 Agent 分别生成不同边类型或边权。
- 可复用文献：MagicNet、Multi-Granularity Graph、Dynamic-Causal Lens、Sensitivity-Aware Dependency Learning、Unleashing Expert Opinion。
- 可能创新：把金融图从“统计相关性图”升级为“叙事/事件/因果多视角图”。
- 风险：Agent 生成图的可靠性需要约束，可引入规则校验、置信度过滤和消融实验。
- 推荐程度：高。GNN 强相关，故事新，但工程复杂度高于方向一。

### 方向三：风险收益一致的推荐排序损失函数

- 核心问题：用金融目标重写推荐排序损失，让训练目标更接近投资目标。
- 推荐系统关联：BPR、LambdaRank、listwise ranking、negative sampling、counterfactual learning。
- 金融约束：均值-方差、CVaR、最大回撤、换手率、交易成本。
- 可复用文献：Temporal Relational Ranking、AlphaStock、Relational Stock Selection、FactorGCL。
- 可能创新：提出 Risk-aware BPR 或 Portfolio-aware Listwise Loss，比较 MSE/CE/BPR/listwise 在收益指标上的差异。
- 风险：如果只改 loss，方法新颖度可能不足；最好与方向一或方向二结合。
- 推荐程度：中高。适合作为主课题中的核心模块。

### 方向四：金融时序-文本双视图对比预训练

- 核心问题：把价格序列视图和 LLM 文本语义视图对齐，学习更稳健的股票表示。
- 推荐系统关联：CL4SRec、DuoRec、SimGCL、SGL、多视图推荐。
- LLM/Agent 角色：生成事件摘要、风险解释、主题标签，作为语义 anchor。
- 可复用文献：FactorGCL、PA-TMM、Integrative LLM + Patch Transformer、TGNS。
- 可能创新：金融时序 residual contrastive learning + LLM semantic alignment。
- 风险：预训练数据和算力要求较高；需要清晰证明比简单拼接特征更好。
- 推荐程度：中。适合后续深入，不一定是第一篇课题的最稳路线。

### 方向五：市场 Regime 检索增强的推荐式预测 Agent

- 核心问题：为当前市场状态检索历史相似 regime，再辅助 Top-K 股票推荐。
- 推荐系统关联：session retrieval、nearest-neighbor recommendation、memory network、case-based recommendation。
- LLM/Agent 角色：解释当前 regime，判断历史片段是否可类比，做反思反馈。
- 可复用文献：MagicNet、Multi-Granularity Graph、Financial News Sentiment、TS-Agent 类工作。
- 可能创新：用推荐系统序列 encoder 做 regime retrieval，比通用向量检索更贴合金融序列。
- 风险：TimeRAG 类工作需要注意会议/版本核验；本方向应强调推荐系统检索器而不是泛 RAG。
- 推荐程度：中。适合与方向一合并成增强模块。

## 5. 交叉分析矩阵

| 推荐系统前沿技术 | 已进入金融场景的证据 | 当前形态 | 仍可深入的空白 |
|---|---|---|---|
| Pairwise/Listwise Ranking | TOIS 2019、TKDE 2025 | 股票相对收益排序、选股 | BPR/listwise 与收益、风险、交易成本联合优化不足 |
| 序列 Transformer | IJCAI 2022、TNNLS 2025、Information Sciences 2025 | 金融时序 self-attention | 与 SASRec/BERT4Rec 的推荐范式连接不足 |
| GNN / 图推荐 | TOIS 2019、TKDE 2025/2026 多篇 | 股票关系图、动态因果图、专家图 | 图构建依赖统计相关，缺少 LLM/Agent 解释型构图 |
| 超图推荐 | AAAI 2025 FactorGCL | 股票-因子高阶关系 | 可引入推荐系统多视图超图增强和 hard negative |
| 对比学习 | FactorGCL | 时序残差对比 | LLM 语义视图与金融数值视图对齐不足 |
| 多模态推荐 | TNNLS 2025、ESWA 2026 | 新闻/图像/价格融合 | 多模态信号与排序目标仍松耦合 |

## 7. 建议优先落地的一个课题雏形

题目可暂定为：

**LLM-Enhanced Sequential Recommendation for Risk-Aware Stock Selection**

核心设计：

- 主干模型：SASRec / BERT4Rec / SR-GNN 之一，输入为股票历史状态 token 序列；
- LLM 模块：从新闻/公告/宏观事件中抽取事件 token、风险标签、主题标签；
- 融合方式：事件 token 作为 side sequence，或作为 attention bias / graph edge weight；
- 训练目标：BPR/listwise ranking + 风险正则（波动率、回撤、换手率）；
- 评估指标：RankIC、NDCG@K、Top-K 组合收益、Sharpe、MDD、turnover、交易成本后收益；
- 对比基线：LSTM/Informer、纯 SASRec、纯 LLM 情感特征、GNN 股票关系模型、LLM+Transformer 松耦合模型；
- 关键消融：无 LLM、无图、无风险正则、无负采样策略、不同市场 regime。

这个方向的优点：

- 导师能看到推荐系统主线；
- 你能做 LLM/Agent；
- 期刊写法上可定位为“推荐系统技术迁移到金融科技应用”，而不是“又一篇 LLM 股价预测”；
- 后续可扩展到基金推荐、智能投顾、信用风险排序、欺诈风险排序等 fintech 场景。
