#### Integrative stock price trend prediction via hierarchical LLM text processing and patch-based transformer with co-attention

Expert Systems With Applications 2026

Nanjing Normal University

- 现有方法通常不能同时做到：长金融文本的层级语义抽象、多尺度时间序列建模、低计算成本

- 把价格序列和文本-价格对齐后的序列切成重叠 patch，再用 Transformer/self-attention 编码。类似 PatchTST 的思想。
- ~~文本分支负责抽取语义，价格分支负责建模时间序列。这就是典型的双模态结构。论文把文本 embedding 和价格特征投影到共同空间~~
-  **co-attention 融合**
  模型最关键的部分。它有两条注意力流：
  `text -> price`：文本特征查询价格特征，用新闻语义定位相关价格模式。
  `price -> text`：价格特征查询文本特征，用价格变化反过来筛选关键新闻语义。

结论：本文模型优于所有基线，尤其在 CMIN-CN 上准确率提升很明显。

#### TGNS: A transformer-based graph neural network for stock trend  forecasting

Information Sciences 2025

沈阳计算所

- 股票预测中忽略股票间关系的问题，静态概念图无法适应市场变化的问题

- 结合 Transformer 和图神经网络的股票趋势预测框架。它用 CGA 建模动态概念关系，用 SGA 建模股票间全局关系，并提出 WRL 加权鲁棒损失来提升高收益股票预测能力。

- CGA = 概念图注意力模块，SGA = 股票图注意力模块

- 如果两只股票属于同一行业或同一板块，就认为它们有边，用行业/板块图作为先验结构，但用 CGA 在每个时间点动态计算注意力权重，让概念关系强度随市场状态变化。CGA = 在概念图上做带 mask 的图注意力聚合‘

- SGA = 在全股票图上做全局注意力聚合

- 首先用 Transformer Encoder 编码股票历史量价序列；然后用 CGA 捕捉行业、板块、概念内的动态关系；再用 SGA 捕捉任意股票之间的全局交互；最后用 WRL 损失函数增强模型对异常值的鲁棒性，并提高高收益股票权重。

- CGA 聚合概念邻居信息后，还会做残差处理：

  - 一部分表示 **概念/行业能解释的收益**
  - 另一部分表示 **概念/行业解释不了的残差信息**

- 论文解决静态概念图问题的方法是：

  > **用行业/板块图作为先验结构，但用 CGA 在每个时间点动态计算注意力权重，让概念关系强度随市场状态变化。**

- TGNS 通过“原始表示 - 概念解释表示”的残差，把概念图解释不了的信息保留下来，再交给后续模块继续学习。

- 在 IC、RankIC、Precision@N 和累计收益上整体优于 LR、MLP、LSTM、GRU、GATS、ALSTM、Transformer、HIST、MGAR、Informer、PatchTST 等模型

| IC          | 预测值和真实收益的相关性      | 整体预测信号质量         |
| RankIC      | 预测排名和真实排名的一致性    | 选股排序能力             |

#### Kronos: A Foundation Model for the Language of Financial Markets

清华

通用时序基础模型在金融 K 线任务上常不如专用的非预训练模型。现有模型侧重单一预测任务，较少同时处理波动率预测、K 线生成、投资应用等金融关键任务。现有预训练语料又缺乏金融数据，任务覆盖也不足。

与直接预测连续数值不同，论文先把每根 K 线映射为离散 token，之后把预测问题转为“根据历史 token 自回归预测未来 token”的生成问题。这使预测、波动率估计和合成数据生成可统一在同一框架内。

使用 Transformer 自编码器与 Binary Spherical Quantization（BSQ），将连续 K 线压缩成二进制离散码

一个 token 被拆成两个子 token：

- 粗粒度 token：捕捉主要价格—成交活动结构；
- 细粒度 token：补充粗粒度表示未覆盖的细节。

离散 token 再输入 Tokenizer Decoder 重建原始 K 线。模型学到一种带层级结构的金融“词表”。



像语言模型一样预测未来 token，用 decoder-only Transformer 建模 token 序列。每一步先预测粗 token，再在粗 token 和历史上下文条件下预测细 token。

模型先预测时点 \(t\) 的粗 token：对应“下一根 K 线大概处于什么市场状态”，例如整体趋势、波动强弱、量能格局。再预测细 token：粗 token 作为 Query，历史 Transformer 表示作为 Key/Value。
因此，细 token 会在“已确定的粗市场状态”下，补足精细的 OHLCVA 变化。

价格预测的 RankIC：相对最强 TSFM 提升 **93%**，相对最佳非预训练模型提升 **87%**，其余指标也大幅提升



#### TermGPT: Multi-Level Contrastive Fine-Tuning for Terminology Adaptation in Legal and Financial Domains

浙大

问题：法律、金融等高风险领域中，LLM 容易混淆语义相近但业务含义不同的专业术语。例如将“监事”误解为“执行监事”，可能导致贷款审核错误。

现有 LLM 的嵌入空间存在“各向同性”问题，术语向量区分度不足。术语适配面临三项困难：监督信号高度依赖上下文、术语在语料中极稀疏、全局上下文与局部术语语义难以兼顾。为此提出术语感知微调（terminology-aware fine-tuning）任务和 TermGPT 框架。

思路：

- 句子级对比学习擅长建模整体语义，但会稀释术语的细粒度差异。
- 词元级对比学习能强化术语区分，却容易缺少上下文和句间依赖。
- 因而需要将两种粒度结合。

TermGPT 分为两阶段：**基于句子图的数据增强**，以及**句子级 + 词元级的多层对比学习**。

句子级子图的作用是：**找出“整句话意思接近、但规则结论不同”的句子，并用它们训练模型理解上下文。**

1. 把每个规则句子作为一个节点；
2. 若两个句子共享实体或属于同类规则，就在它们之间连边；
3. 选一个句子作锚点（正确答案），从相连句子中找候选句（干扰项）；
4. 生成“问题 + 正确句子 + 相似但错误的句子”的选择题；
5. 用句子级对比学习，让问题的表示更接近正确句、远离干扰句。

词元级子图专门处理：**两个术语很像，但其实不能混用**的问题。

1. 先在句子中抽取关键术语/实体；
2. 计算不同术语的嵌入相似度；
3. 相似度高于阈值的术语之间，添加词元级边 \(edge_{token}\)；
4. 选一个术语作为锚点（正确术语），把相似术语作为候选干扰项；
5. 根据该术语所在句子，让 LLM 生成术语选择题；
6. 用词元级对比学习，让模型提升正确术语的概率、降低相似错误术语的概率。

先做 SFT，先对 \(Q_{sen}\) 与 \(Q_{tok}\) 统一进行监督微调（SFT），使模型掌握“根据问题输出正确答案”的基本任务映射。

#### 句子级对比学习

句子级模块使用 \(Q_{sen}\)。模型通过双向注意力获得问题、正确答案和错误选项的上下文嵌入，并采用 InfoNCE 损失：

- 拉近问题 \(q\) 与正确答案 \(a\)；
- 推远问题 \(q\) 与错误候选 \(c_1,c_2,c_3\)。

它解决的是“术语不能脱离上下文理解”的问题：例如同一个词在不同法律条款、金融监管语境中可能含义不同。

#### 词元级对比学习

词元级模块使用 \(Q_{tok}\)，更关注“正确术语与错误术语只差一点点”的情况。流程是：

1. 将“问题 + 正确答案”改写为包含正确术语的陈述句；
2. 将正确术语 \(z^+\) 替换为错误术语 \(z^-\)，得到混合句；
3. 用二值掩码标记哪些位置来自正确术语或原上下文，哪些位置来自错误术语；
4. 训练模型提高正确词元的概率，并压低错误替换词元的概率。

#### FinMMDocR: Benchmarking Financial Multimodal Reasoning with Scenario Awareness, Document Understanding, and Multi-Step Computation

北邮

相关研究分为三类：

- 金融数值推理基准，如 FinQA、TAT-QA、FinanceMath；
- 金融多模态基准，如 FinMMR、FinMME、MME-Finance；
- 长文档多模态理解与 RAG，如 MMLongBench-Doc、LongDocURL、ColPali、ColQwen2.5、ViDoRAG 等。



有金融问答或文档问答基准与真实金融分析工作存在三项缺口：

- 缺少真实金融情境：很多任务只给出明确条件，不要求模型结合市场背景作合理假设。
- 缺少复杂多模态文档理解：现有数据常是纯文本或单张图表，不能反映真实研报、财报中跨页文字、表格、K 线图等信息。
- 缺少严格的多步骤精确计算：金融任务对单位、百分比、小数位和计算精度要求高，而以往评测往往过于宽松。



因此，FinMMDocR 从“情境理解—文档取数—多步计算”三个环节评测模型。

- 大部分模型处理图像形式长文档时，反而不如 OCR 后交给纯文本 LLM；o4-mini-high 是少数图像输入优于文本输入的模型。
- 情境越多、文档越长、证据页越靠后、抽取或计算步骤越多，模型准确率越低。
- 错误主要来自文档理解/信息抽取，而非纯算术

rag 的检索阶段

- 视觉检索优于纯文本检索，因为金融文档的关键证据经常存在于表格、图表和版面中。

- 多步骤 Agentic RAG 并未超过较简单的视觉检索方案，且耗费更多 token 和时间。
- Agent 工作流过长会放大上游检索、推理或计算错误，形成误差传播；迭代代理还存在延迟高、收益有限的问题。
