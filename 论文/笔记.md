### Large Language Model Agents in Finance: A Survey Bridging Research, Practice, and Real-World Deployment

ACL2025

niversity of Washington

- 现有金融 LLM 研究多聚焦单点任务：情绪分析、财报问答、股价预测等。
- 但真实金融机构是多部门协作系统：数据、投研、交易、组合、风控相互依赖。
- 提出金融 LLM Agent 分类框架：
  Data Analysis Agent → Investment Research Agent → Trading Agent → Investment Manager Agent → Risk Management Agent。
- 将金融核心角色（数据分析、投资研究、交易、投资管理、风险管理）映射到主要子任务（并串成agent工作流）、数据集和评估指标。关键子任务包括：TS（文本摘要）、NER（命名实体识别）、FRE（金融关系抽取）、EC（事件分类）、SA（情绪分析）、**TSF（时间序列预测）**、SE（策略执行）、QA（问答）、FD（欺诈检测）、DRP（违约风险预测）和 MAC（多智能体协作）,并综合了对应的30 多个 benchmark 和 20 多个模型以及一些真正的agent
- 将历史价格数据与文本信号结合，以预测市场走势。StockNet 提供两年内 88 只 S&P 500 股票的价格数据，并与 StockTwits 评论对齐；Bigdata22 和 CIKM18 将社交媒体和价格数据结合；FinTSB 进一步统一了实时数据摄取、极端事件模拟和成本建模。许多 benchmark 仍缺乏多资产覆盖和基本面指标，例如市盈率等。

### R&D-Agent-Quant A Multi-Agent Framework

2025  NeurIPS  

CMU

人工依赖强、因子和模型开发割裂、LLM 直接生成交易信号不够可解释。

把量化研究做成一个多智能体闭环：自动找因子、写代码、回测、看结果、再迭代。

通过协调式的因子-模型联合优化，自动化完成量化策略的全栈研发。R&D-Agent(Q) 将量化流程拆解为两个迭代阶段：Research 阶段会动态设置与目标对齐的提示词，基于领域先验形成假设，并将其映射为具体任务；Development 阶段使用代码生成智能体 Co-STEER 来实现特定任务代码，并在真实市场回测中执行

在 Research 阶段，Specification Unit 会根据优化目标生成标准化任务说明。Synthesis Unit 会基于先前结果生成面向任务的知识森林，并生成新的因子或模型假设，再将这些假设映射为可执行任务。

在 Development 阶段，引入 Co-STEER，这是一个代码生成智能体，利用链式思维推理和基于图的知识存储。Implementation Unit 将假设翻译为代码，而 Validation Unit 会执行真实市场回测。Analysis Unit 使用统一指标进行评估，并使用多臂老虎机调度器自适应选择下一步优化方向。

### TRADE IN MINUTES! RATIONALITY-DRIVEN AGENTIC SYSTEM FOR QUANTITATIVE FINANCIAL TRADING

ICLR2026

Tongji University 

把“策略开发”和“实盘执行”解耦，先离线生成、优化交易机器人，再在线上用程序化机器人分钟级执行

论文批评传统 LLM 金融智能体常模拟分析师、交易员、辩论者等拟人角色，容易引入情绪偏差和主观判断。TiMi 转而依赖技术指标、数学约束和程序化执行，更贴近量化交易逻辑。

系统设计了四类智能体：宏观分析、策略适配、机器人进化、反馈反思。它们分别负责从市场模式提炼策略、针对交易对定制、生成交易代码、根据反馈优化参数和逻辑。

**宏观分析智能体 A_ma**
负责看“大盘模式”。它从市场数据和技术指标中识别宏观规律，比如趋势、震荡、波动放大、成交量异常等，然后生成一组通用交易策略 S。

**策略适配智能体 A_sa**
负责把通用策略改造成适合具体交易对的策略。比如 BTC、ETH、XMR、山寨币的波动率、流动性、资金费率都不同，所以不能完全用同一套参数。A_sa 会生成交易对特定规则 S_P 和初始参数 Θ_P。

**机器人进化智能体 A_be**
负责把策略写成可以执行的程序化交易机器人。它用代码能力把策略变成交易逻辑，包括下单规则、价格层级、仓位管理、止盈止损、API 调用等。

原型机器人 B 会先在离线环境中模拟交易，得到行动反馈 F

**反馈反思智能体 A_fr**
不只是“总结失败原因”，而是把失败案例转成数学约束。

### Reasoning_on_Time_Series

2026iclr

高瓴

现有金融 LLM 多分析新闻、财报、社交文本，较少直接解释历史价格数据，即技术分析。时间序列 LLM 虽能预测，但通常牺牲语言推理能力。

论文提出 VTA，将“语言化推理”和“潜在时间序列建模”结合，目标是同时提高预测准确性和可解释性。

把股价序列转成技术指标文本，让LLM 做自然语言推理和给初步预测

时间序列模型做数值预测，VTA 会从 LLM 的粗略预测或推理中提取一些属性去影响时序模型的最终输出

解释强依赖技术指标，不一定代表真正因果解释。

在非金融时间序列上效果有限，说明方法对金融场景依赖较强。

### 知识点

因子：因子可以理解成用市场数据构造出来的特征，用来预测未来收益。比如价格、成交量、波动率、动量、反转、换手率等。

Alpha：量化金融里的 Alpha，通常指能带来超额收益的交易信号/因子

IC 评价指标指的是 Information Coefficient，信息系数，在量化投资里常用来衡量一个 Alpha 因子有没有预测能力。IC 衡量的是：因子预测值和未来真实收益之间的相关性。
