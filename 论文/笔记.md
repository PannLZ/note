#### Financial news sentiment meets market data: A large language model-based approach to stock price prediction

Information Sciences 2026

- 现有研究要么只用价格和经济指标，要么只研究情感与股价相关性，较少系统比较“LLM 情感 + 技术指标 + 深度预测模型”的组合效果
- 如何把金融新闻标题中的情绪信息，通过通用 LLM 零样本抽取出来，并与历史市场数据、技术指标结合，用于股票收盘价预测

- 将通用开源 LLM 的零样本金融情感抽取接入股票价格预测流程

新闻标题
 -> LLM 提取情感分数
 -> 按日期聚合成情感特征
 -> 与技术指标/历史价格合并
 -> 输入 LSTM/GAN/Transformer
 -> 预测股票收盘价
 -> 用测试集误差评价

| 配置            | MAE    | RMSE   | $MAPE  |
| --------------- | ------ | ------ | ------ |
| LSTM + Vicuna   | 0.1301 | 0.1630 | 12.904 |
| LSTM + Economic | 0.1253 | 0.1570 | 12.298 |

 `LSTM + Vicuna` 的 loss 略低，但核心预测误差 MAE、RMSE、MAPE 都是 `LSTM + Economic` 更好

| 配置                   | MAE    | RMSE   | $MAPE  |
| ---------------------- | ------ | ------ | ------ |
| Transformer + Vicuna   | 0.1436 | 0.1800 | 11.504 |
| Transformer + Economic | 0.1317 | 0.1650 | 9.995  |

Transformer 也是 Economic baseline 最好，而且它还是全表 $MAPE 最低的配置。

#### MMRepAgent: Explainable stock earnings forecasting via multimodal report agent framework

Knowledge-Based Systems 2026

South China University of Technology

普通投资者很难同时理解量化指标和大量非结构化金融新闻；直接问 LLM 又依赖用户会提专业问题

- 用一个多模态金融报告 Agent，把股票结构化因子、金融新闻语义事件、收益预测、风险评估和 LLM 报告生成串成端到端系统，面向普通投资者输出可解释的投资分析报告。
- 用户只需输入股票代码或新闻片段，系统自动检索数据、建模、预测收益和风险，并生成包含文字、图表、事件知识图谱的报告。
- 用户请求输入，数据检索与时间对齐，股票因子化 Stock Factorization，新闻因子化 News Factorization， 用 RoBERTa、SRL、SDPG 和图神经网络把新闻转成事件知识图谱和新闻影响因子，股票因子与新闻因子融合， 收益预测 Return Forecasting。把新闻转成“事件级影响因子”，**能够表达谁影响谁、事件关系、时间衰减和潜在市场冲击。**
- **SRL**：Semantic Role Labeling，语义角色标注。**SDPG**：Semantic Dependency Parsing Graph，语义依存解析图。**RoBERTa**：一种基于 BERT 改进的预训练语言模型。作用是把文本编码成向量，让模型能理解词义、上下文和金融新闻的语义特征。
- 股票因子 + 新闻事件因子进入两个核心模块：
  - `Return Forecasting Tool`：预测未来收益，基于扩展版 Fama-French 5 因子模型，并加入新闻影响和时间衰减。
  - `Risk Assessment Tool`：预测风险，基于扩展 EGARCH，加入新闻事件冲击，输出 VaR / EVaR 等风险指标。
- MMRepAgent 表现优于 FinAgent、FinReport 等 baseline

#### Integrative stock price trend prediction via hierarchical LLM text processing and patch-based transformer with co-attention

Expert Systems With Applications 2026

Nanjing Normal University

- 现有方法通常不能同时做到：长金融文本的层级语义抽象、多尺度时间序列建模、低计算成本
- 原始新闻太长、太杂、重复多，直接送入模型效果不好。每个小时内的新闻由 LLM 压缩成“小时摘要”。然后把一天内所有小时摘要按时间顺序拼接，再输入 LLM 生成“日级摘要”。最后提取文本 embedding。
- 文本摘要得到 embedding 后，不能直接和价格序列拼接。作者先把文本特征映射到与价格特征一致的维度，再用 cross-attention 做初步对齐，让价格特征和文本语义进入同一个表示空间。
- 把价格序列和文本-价格对齐后的序列切成重叠 patch，再用 Transformer/self-attention 编码。类似 PatchTST 的思想。
- 文本分支负责抽取语义，价格分支负责建模时间序列。这就是典型的双模态结构。论文把文本 embedding 和价格特征投影到共同空间
-  **co-attention 融合**
  模型最关键的部分。它有两条注意力流：
  `text -> price`：文本特征查询价格特征，用新闻语义定位相关价格模式。
  `price -> text`：价格特征查询文本特征，用价格变化反过来筛选关键新闻语义。

#### TGNS: A transformer-based graph neural network for stock trend  forecasting

Information Sciences 2025

沈阳计算所

- 股票预测中忽略股票间关系的问题，静态概念图无法适应市场变化的问题

- 结合 Transformer 和图神经网络的股票趋势预测框架。它用 CGA 建模动态概念关系，用 SGA 建模股票间全局关系，并提出 WRL 加权鲁棒损失来提升高收益股票预测能力。

- CGA = 概念图注意力模块，SGA = 股票图注意力模块

- 如果两只股票属于同一行业或同一板块，就认为它们有边，用行业/板块图作为先验结构，但用 CGA 在每个时间点动态计算注意力权重，让概念关系强度随市场状态变化。CGA = 在概念图上做带 mask 的图注意力聚合‘

- SGA = 在全股票图上做全局注意力聚合

- 首先用 Transformer Encoder 编码股票历史量价序列；然后用 CGA 捕捉行业、板块、概念内的动态关系；再用 SGA 捕捉任意股票之间的全局交互；最后用 WRL 损失函数增强模型对异常值的鲁棒性，并提高高收益股票权重。

- CGA 聚合概念邻居信息后，还会做残差处理：

  - 一部分表示 **概念/行业能解释的收益**
  - 另一部分表示 **概念/行业解释不了的残差信息**

- 论文解决静态概念图问题的方法是：

  > **用行业/板块图作为先验结构，但用 CGA 在每个时间点动态计算注意力权重，让概念关系强度随市场状态变化。**

- TGNS 通过“原始表示 - 概念解释表示”的残差，把概念图解释不了的信息保留下来，再交给后续模块继续学习。

- 在 IC、RankIC、Precision@N 和累计收益上整体优于 LR、MLP、LSTM、GRU、GATS、ALSTM、Transformer、HIST、MGAR、Informer、PatchTST 等模型

#### FinRpt: Dataset, Evaluation System and LLM-based Multi-agent Framework for Equity Research Report Generation
