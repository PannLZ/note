#### PixelRec: From Modality-Level Fusion to Signal-Patch-Level Fusion for Multimodal Sequential Recommendation

**文本内容首先被转化为可视化文本，然后与原始图像结合形成统一的视觉输入。**

这个承载视觉和文本内容的统一输入随后通过视觉编码器被编码成信号块。这些信号块被视为后续融合的基本融合单元。为了自适应地将这些信号块融合到物品表示中，我们进一步引入了一个视觉推荐聚合器。

- **patch 提供“这个商品有什么内容”**
  它们来自统一图文输入，因此同时含有视觉和文本语义。
- **ID embedding 提供“这个商品在用户行为中意味着什么”**
  例如，一个商品的图片上既有颜色、品牌、容量等信息，但历史交互数据可能表明：对这个商品而言，“品牌”或“颜色”更能影响后续购买，而背景几乎没有用。
- **VRA 用 ID embedding 调整 query，再计算各 patch 的注意力权重**
  因而同一个商品的不同局部区域会得到不同权重；重要 patch 权重大，不重要 patch 权重小。
- **对加权后的 patch 求和并投影**
  得到最终向量 \(e_i\)。因为被汇总的内容来自图像区域和视觉化文字区域，所以它是该商品的**多模态表示**；因为权重受 ID 的协同信号引导，所以它也是**更适合推荐**的表示。



**Render to Visual Layout（统一视觉排版）**
把商品标题渲染成图片中的文字，并和商品主图拼在一起。这样图和文字从输入开始就处于同一个视觉空间，不再是两条独立模态分支。

**VLM Encoder（视觉语言模型编码器）**
用冻结的 VLM 视觉编码器读取统一图文版式，输出大量局部 token。每个 token 对应商品图或标题文字附近的一块区域。

**DownSample / Average Pooling（下采样）**
原始 token 太多，因此用平均池化合并相邻 token，得到较少但仍保留局部语义的 **signal patches**。
它实现了论文最关键的改变：融合对象不再是整张图或整段文本，而是局部图文信号块。

**RCC：Re-Construction Compression（重构压缩）**
将每个高维 patch 压缩成低维表示，同时用解码器尝试还原原特征，并通过重构损失防止重要信息丢失。
目的：将压缩后的 patch 离线缓存，降低后续推荐训练的显存占用。

**ID Embedding Layer（物品 ID 表征）**
从用户历史交互的物品 ID 中学习协同过滤信号，即“哪些物品常被相似用户一起消费”。

**MM Embedding Layer（多模态特征读取）**
读取每个物品已缓存的压缩 patch 特征；图中带雪花的部分表示这类 VLM 特征在推荐训练时保持冻结。

**VRA：Vision-Recommendation Aggregator（视觉-推荐聚合器）**
这是推荐阶段的核心融合模块。它用物品 ID 表征作为 **Query**，在多模态 patches 中做注意力检索：  

- ID 信号决定“对于这个商品/用户偏好，应优先看什么”；  
- patches 提供图像与标题中的局部内容；  
- 最后对重要 patch 加权求和，生成物品的融合表示。

因此，它不是判断“图像整体更重要还是文本整体更重要”，而是判断“商品图中的哪个区域、标题中的哪些词更值得用于推荐”。

**Sequence Encoder + Prediction Layer（序列编码与预测）**
将用户历史点击过的物品融合表示按时间顺序建模，最后预测用户下一步最可能交互的物品。



#### CLER: Improving Multimodal Financial Reasoning by Cross-MLLM Error Reflection

University of Auckland, Auckland, New Zealand

AAAI-26

金融问答往往同时涉及文本、表格、图表、专业术语和计算，现有 MLLM 容易出现公式误用、逻辑不一致和视觉-文本整合错误。CLER 先用开源模型构建“错误步骤—正确步骤”数据库，再训练对比学习检索器，为闭源模型当前推理链的每一步找相似错误案例；闭源模型据此进行针对自身推理过程的反思和修正。



CLER 方法

- 任务定义：输入包括金融文本、问题、图像/表格和候选答案；模型需生成可解释的逐步推理并选出正确答案。
- 错误库 FinErrorSet：用 DeepSeek-VL-2、Qwen2.5-VL、InternVL-3 在 FinMR 与 FAMMA 训练题上生成推理链，识别错误步骤并改写为正确步骤。最终获得 3,258 道题、8,852 组步骤级“错误—修正”对，其中专业知识推理占 58%，数学推理占 42%。
- 对比检索器：以错误步骤为锚点、对应正确步骤为正样本，通过 SupSimCSE（有监督的简单对比学习句向量方法） 式对比学习，不只匹配表面语义，也学习推理结构相似性。让模型学会识别**结构和语义上相似的推理错误**，例如两段表述不同、但都犯了“公式适用条件错误”或“漏掉负号”的错误。这样测试时就能为当前推理步骤找出更有参考价值的历史错误—修正案例。
- 逐步反思与修正：闭源模型先生成推理链；对每一步检索最相似的错误—修正对；再自行判断是否存在同类问题并改写该步骤。关键不在机械套用答案，而在形成与当前推理路径匹配的“个性化洞见”。

在 FinMR、FAMMA、MMMU-Finance 三个金融多模态基准上，CLER 对 GPT-4o、Gemini-2.0-flash、Claude-4-sonnet 均优于 CoT、LEAP 和 RICP。



CLER 通过以下方式应对这些挑战：(1) 训练一个对比检索模型，该模型捕捉推理步骤之间的语义和结构相似性，以识别有意义的、特定于任务的错误实例；(2) 通过允许每个 MLLM 适应其自身的推理风格来检索错误，而不是直接转移泛化的错误规则，从而实现个性化反思；以及 (3) 检索细粒度的、步骤级别的错误修正对，从而能够有针对性地识别上下文相关的错误（例如，在步骤 3 中误用公式或在步骤中遗漏负号）



>**CoT**：直接要求闭源模型“逐步思考”，作为最基础的推理基线。
>
>**LEAP**：从过去错误中预先归纳一些通用纠错原则，再把原则放进提示词，让闭源模型参考。
>
>**RICP**：检索以往错误案例，为当前问题构造针对性的原则，再交给闭源模型推理。



#### CAMEF: Causal-Augmented Multi-Modality Event-Driven Financial Forecasting by Integrating Time Series Patterns and Salient Macroeconomic Announcements

西财

kdd-25

**融合时间序列模式与显著宏观经济公告的因果增强多模态事件驱动金融预测**

将宏观经济公告文本与公告前的 5 分钟级金融时序共同输入，用于预测公告后 175、350、700 分钟的市场走势。核心思路是：真实公告应与其对应的市场反应更匹配；通过 LLM 生成“改变情绪或关键数值、但保留中性内容”的反事实公告，并用对比/三元组损失拉近真实公告与实际市场时序、推远反事实公告，从而增强模型对事件驱动因素的辨识。

 LLM 的作用是：

> 批量生成可信、但未真实发生的公告文本，充当训练时的反例，帮助模型辨别“公告内容”是否真是市场反应的原因。

- 回归头：多层回归网络输出未来多个时间点的价格预测。**Post-Regressor**：将解码结果映射为具体的多步价格预测。
- 因果学习模块：构造两类负样本——同类事件的反事实版本，以及日期相近但类型不同的宏观事件；用三元组损失让真实文本表示比反事实文本更接近对应的市场时序表示。是训练**事件文本和市场时序的表示空间**：让模型知道当前市场状态究竟更符合哪一份公告。

总损失为预测损失（MSE + MAE）与因果三元组损失之和。

MSE相比最佳单模态基线 iTransformer降低 62.55%，相比最佳多模态基线 TEST（2024 iclr）降低 33.55%

#### **STORM: A Spatio-Temporal Factor Model Based on Dual Vector Quantized Variational Autoencoders for Financial Trading**

NTU

> **VQ-VAE**：（向量量化变分自编码器）一种把连续特征压缩后，再映射到有限“码本”中的离散向量表示的模型。可理解为：模型从若干个可学习的“因子原型”中，为当前市场状态挑选最相近的一类，起到去噪、聚类和因子选择作用。
>
> **VAE 因子**：指用变分自编码器（VAE）从市场数据中自动学习出来的潜在因子。传统因子是人工定义的，例如市值、价值、动量；VAE 因子则把价格、成交量、技术指标等高维输入压缩为几个低维隐变量。这些隐变量不一定有直观的经济名称，但模型希望它们能概括影响股票未来收益的共同市场驱动因素。
>
> **“码本”（codebook）**是模型内部一组可学习的向量库，类似一套“原型词典”。VQ-VAE 先将输入编码成连续向量，再在码本中找距离最近的向量来替代它；这个被选中的码本向量就是离散化后的表示。在 STORM 里，每个码本向量可理解为一种潜在市场/因子模式的中心，例如某类趋势、波动或股票间联动状态。两个 VQ-VAE 各有自己的码本，分别服务于时间序列和横截面信息。
>
> “**横截面”**指同一个时间点，对多只股票进行横向比较
>
> **VAE：**VAE 像是把复杂数据映射到一张有规律的“隐空间地图”上：相似样本位置相近。因为这张地图是概率化且连续的，你可以从中采样新位置，再经解码器生成新的、合理的样本。普通自编码器把输入 \(x\) 压缩为一个固定向量 \(z\)，再尝试还原：VAE 的不同在于：编码器不直接给出一个固定的 \(z\)，而是给出一个概率分布，例如正态分布的均值和方差：因此，它学习的是“数据可能处在什么潜在状态分布中”，而不只是记住每个样本的压缩编码。
>
> | 模型            | 更擅长做什么                                                 | 核心特点                         |
> | --------------- | ------------------------------------------------------------ | -------------------------------- |
> | 普通自编码器 AE | 降维、去噪、特征提取、异常检测、压缩                         | 每个输入对应一个确定的隐变量向量 |
> | VAE             | 生成新样本、缺失值补全、不确定性建模、可控表征学习，也可做异常检测 | 每个输入对应一个隐变量的概率分布 |
>
> 例如：
>
> - **AE**：输入一张有噪声的图片，压缩后再还原干净图片；或把 152 个金融特征压成一个较短的特征向量，供后续预测模型使用。
> - **VAE**：学习大量人脸的潜在分布后，可以随机采样一个隐变量，生成一张此前不存在、但看起来合理的新脸；金融中则可用于学习市场状态的潜在分布、生成情景或提取带不确定性的因子。

**双 VQ-VAE**：时间序列模块按“个股 × 时间片段”切分，横截面模块按“某日全部股票”切分；两个 Transformer 编码器分别提取特征，各自经码本量化为离散表示，再由解码器重构输入。  

**码本约束**：使用多样性损失鼓励均衡使用码字，用正交损失降低因子相关性/多重共线性。  

**因子融合**：以跨注意力实现细粒度时空融合，以对比学习在语义层面对齐两种表示。  

**先验—后验学习**：训练时结合真实未来收益形成后验，推理时只从历史特征得到先验，避免未来信息泄漏；最终按因子模型预测收益。  

**下游应用**：预测收益用于组合配置；潜在因子嵌入用于 PPO 交易策略的状态输入。

1.**时间序列模块（TS Module）**

**Patching**
沿时间轴将每只股票的历史数据切成长度为 \(p\) 的小片段。也就是说，一个 token 对应“某股票连续 \(p\) 天”的信息。

**TS Transformer Encoder**
编码器用自注意力学习同一股票在不同时间片之间的关系，得到连续的时间序列潜在特征：

**TS Codebook：向量量化**
每个连续特征被映射到时间序列码本中距离最近的向量，形成离散特征：

可以将码本理解为一组可学习的“典型时序模式原型”，如趋势、反转、震荡等的隐式类别，但它们并不具有传统金融因子的直接语义标签。

**TS Transformer Decoder**
从量化后的表示重构原始时间序列数据。重构任务迫使编码器保留原始市场数据的关键信息。

decoder 的价值是：**防止时间序列与横截面隐变量只迎合收益预测、却丢失市场结构信息。** 

中间：因子模块（Factor Module）

TS 和 CS 分支各自有效，但它们的 token 组织方式不同，不能直接拼接，所以需要因子模块把它们统一到同一个因子空间。

细粒度融合：Multi-scale Encoder / Cross-Attention

图中央的多尺度编码器通过跨注意力，让：

- 时间序列特征去关注与其相关的横截面状态；
- 横截面特征去关注关键的个股时序变化。

这一步回答的是：**某只股票的走势，放在当前整体市场和同类股票环境中，意味着什么？**

**语义级对齐：Contrastive Learning**

对比学习进一步约束 TS 和 CS 表示：

- 同一或相似市场状态下，两条分支的表示应更接近；
- 不同市场状态下的表示应更远。

所以，跨注意力负责“信息交互”，对比学习负责“语义一致”。

最终再把对齐后的两路序列合并，得到最终时空因子嵌入。
